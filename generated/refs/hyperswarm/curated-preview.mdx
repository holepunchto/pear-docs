<Status level="stable" />

Hyperswarm is the high-level networking layer for discovering peers by a shared 32-byte topic and opening encrypted connections between them. Prefer one swarm instance per app and join multiple topics on that same instance when possible.

## Install

```sh
npm i hyperswarm
```

## Quickstart

```js
import Hyperswarm from 'hyperswarm'

const server = new Hyperswarm()
const client = new Hyperswarm()

server.on('connection', socket => {
  socket.end('hello from the server')
})

client.on('connection', socket => {
  socket.once('data', async buf => {
    console.log(buf.toString())
    await Promise.all([client.destroy(), server.destroy()])
  })
})

const topic = Buffer.alloc(32).fill('pear-docs-topic')
const discovery = server.join(topic, { server: true, client: false })
await discovery.flushed()

client.join(topic, { server: false, client: true })
await client.flush()
```

## API Reference

### Constructor and state

#### `new Hyperswarm(opts = {})`

[src](https://github.com/holepunchto/hyperswarm/blob/v4.17.0/index.js#L24)

Creates a Hyperswarm instance for discovering peers by topic and opening encrypted connections to them over HyperDHT.

| Parameter | Type | Default |
| --- | --- | --- |
| `opts` | [`HyperswarmOptions`](#hyperswarmoptions) | `{}` |

```js
const Hyperswarm = require('hyperswarm')
const swarm = new Hyperswarm()
swarm.on('connection', (conn, info) => {
  console.log('new connection', info.publicKey.toString('hex'))
})
```

#### `swarm.connections`

[src](https://github.com/holepunchto/hyperswarm/blob/v4.17.0/index.js#L65)

### Topic membership

#### `swarm.join(topic, opts = {})`

[src](https://github.com/holepunchto/hyperswarm/blob/v4.17.0/index.js#L501)

Start discovering and connecting to peers sharing a common topic. As new peers are connected to, they will be emitted from the swarm as `connection` events.

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `topic` | [`Buffer`](https://nodejs.org/api/buffer.html#class-buffer) | — | must be a 32-byte Buffer. |
| `opts` | [`JoinOptions`](#joinoptions) | `{}` | Discovery options. |

- Returns: `object` — a [`PeerDiscovery`](https://github.com/holepunchto/hyperswarm/blob/v3/README.md#peerdiscovery-api) object.

```js
const topic = Buffer.alloc(32).fill('my-topic')
const discovery = swarm.join(topic, { server: true, client: true })
await discovery.flushed() // wait until announced on the DHT
```

Client mode discovers and dials servers for a topic. Server mode announces that topic and accepts inbound connections. Connections opened in client mode update `peerInfo.topics`; inbound server connections are not tied to a single topic.

#### `await swarm.leave(topic)`

[src](https://github.com/holepunchto/hyperswarm/blob/v4.17.0/index.js#L525)

Stop discovering peers for the given topic.

| Parameter | Type | Description |
| --- | --- | --- |
| `topic` | [`Buffer`](https://nodejs.org/api/buffer.html#class-buffer) | must be a 32-byte Buffer |

- Returns: [`Promise<void>`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Promise) — Resolves when discovery for the topic has stopped.

```js
const topic = Buffer.alloc(32).fill('my-topic')
swarm.join(topic)
await swarm.leave(topic)
```

Leaving a topic stops new discovery work but does not close already-open connections.

#### `swarm.status(topic)`

[src](https://github.com/holepunchto/hyperswarm/blob/v4.17.0/index.js#L487)

Get the [`PeerDiscovery`](https://github.com/holepunchto/hyperswarm/blob/v3/README.md#peerdiscovery-api) object associated with the topic, if it exists.

| Parameter | Type | Description |
| --- | --- | --- |
| `topic` | [`Buffer`](https://nodejs.org/api/buffer.html#class-buffer) | The 32-byte topic buffer to look up. |

- Returns: `object\|null` — The PeerDiscovery session, or null if not joined.

```js
const topic = Buffer.alloc(32).fill('hello world')
swarm.join(topic)
const discovery = swarm.status(topic)
console.log(discovery !== null) // true
```

`status(topic)` returns the underlying `PeerDiscovery`, whose `refresh()` takes no arguments and reannounces or re-looks up with the topic's existing client/server configuration. The object returned by `swarm.join(...)` is a session over that discovery and accepts `{ client, server }` on `refresh(...)`.

#### `await swarm.flush()`

[src](https://github.com/holepunchto/hyperswarm/blob/v4.17.0/index.js#L567)

Wait for any pending DHT announces, and for the swarm to connect to any pending peers (peers that have been discovered, but are still in the queue awaiting processing).

- Returns: [`Promise<boolean>`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Promise) — Resolves to true when all pending connections and announces are settled.

```js
swarm.join(topic)
await swarm.flush() // all reachable peers are now connected
```

`flush()` is global to the swarm rather than scoped to one topic, so it can be comparatively expensive.

### Direct peers and events

#### `swarm.joinPeer(noisePublicKey)`

[src](https://github.com/holepunchto/hyperswarm/blob/v4.17.0/index.js#L543)

Establish a direct connection to a known peer.

| Parameter | Type | Description |
| --- | --- | --- |
| `noisePublicKey` | [`Buffer`](https://nodejs.org/api/buffer.html#class-buffer) | The peer's Noise public key (a 32-byte Buffer). |

- Returns: `void`

```js
const remoteKey = Buffer.from('...', 'hex') // 32-byte Noise public key
swarm.joinPeer(remoteKey)
```

#### `swarm.leavePeer(noisePublicKey)`

[src](https://github.com/holepunchto/hyperswarm/blob/v4.17.0/index.js#L556)

Stop attempting direct connections to a known peer.

| Parameter | Type | Description |
| --- | --- | --- |
| `noisePublicKey` | [`Buffer`](https://nodejs.org/api/buffer.html#class-buffer) | The peer's Noise public key (a 32-byte Buffer). |

- Returns: `void`

```js
const remoteKey = Buffer.from('...', 'hex')
swarm.joinPeer(remoteKey)
swarm.leavePeer(remoteKey) // stop reconnecting
```

If the peer is already connected, `leavePeer(...)` does not close that existing socket.

#### `swarm.on('connection', (socket, peerInfo) => {})`

[src](https://github.com/holepunchto/hyperswarm/blob/v4.17.0/index.js#L305)

Emitted whenever the swarm connects to a new peer.

#### `swarm.on('update', () => {})`

[src](https://github.com/holepunchto/hyperswarm/blob/v4.17.0/index.js#L308)

Emitted when internal values are changed, useful for user interfaces.

#### `swarm.on('ban', peerInfo, err)`

[src](https://github.com/holepunchto/hyperswarm/blob/v4.17.0/index.js#L545)

Emitted when a peer gets banned. `err` is an error object describing the reason for the ban (e.g. firewalled).

### Listening and lifecycle

#### `await swarm.listen()`

[src](https://github.com/holepunchto/hyperswarm/blob/v4.17.0/index.js#L491)

Explicitly start listening for incoming connections. This will be called internally after the first `join`, so it rarely needs to be called manually.

- Returns: [`Promise<void>`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Promise) — Resolves once the server is listening.

```js
await swarm.listen()
console.log('listening for connections')
```

`listen()` is usually called for you after the first `join(...)`, but it is available when you want listening to start earlier.

#### `await swarm.suspend({ log: () => {} })`

[src](https://github.com/holepunchto/hyperswarm/blob/v4.17.0/index.js#L606)

Suspend the swarm disconnecting all peers, suspends server listening and stops discovery of new peers. Useful for suspending when the runtime suspends to pause networking.

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `options` | [`SuspendOptions`](#suspendoptions) | `{}` | Suspend options. |

- Returns: [`Promise<void>`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Promise) — Resolves when the swarm is fully suspended.

```js
await swarm.suspend({ log: console.log })
```

#### `await swarm.resume({ log: () => {} })`

[src](https://github.com/holepunchto/hyperswarm/blob/v4.17.0/index.js#L642)

Resume a suspended swarm refreshing discovery of new peers and servers. Useful for reannouncing to the DHT and reconnecting to peers when the runtime resumes.

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `options` | [`SuspendOptions`](#suspendoptions) | `{}` | Resume options. |

- Returns: [`Promise<void>`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Promise) — Resolves when the swarm has fully resumed.

```js
await swarm.suspend()
await swarm.resume({ log: console.log })
```

#### `await discovery.destroy()`

[src](https://github.com/holepunchto/hyperswarm/blob/v4.17.0/index.js#L588)

Destroys the swarm — closes all active connections, stops all topic discovery, and tears down the underlying DHT node. Pass `{ force: true }` to skip waiting for graceful shutdown.

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `options` | [`DestroyOptions`](#destroyoptions) | `{}` | Destroy options. |

- Returns: [`Promise<void>`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Promise) — Resolves when the swarm and DHT are fully shut down.

```js
await swarm.destroy()
```

### `PeerDiscovery`

#### `await discovery.flushed()`

Wait until the topic has been fully announced to the DHT. This method is only relevant in server mode. When `flushed()` has completed, the server will be available to the network.

#### `await discovery.refresh({ client, server })`

Update the `PeerDiscovery` configuration, optionally toggling client and server modes. This will also trigger an immediate re-announce of the topic, when the `PeerDiscovery` is in server mode.

Refreshing a server-mode discovery also triggers a new DHT announcement for that topic.

### `PeerInfo`

#### `peerInfo.publicKey`

The peer's Noise public key.

#### `peerInfo.topics`

[src](https://github.com/holepunchto/hyperswarm/blob/v4.17.0/index.js#L659)

Returns an iterator of all currently joined `PeerDiscovery` instances.

- Returns: `IterableIterator<object>` — An iterator of PeerDiscovery instances.

```js
for (const discovery of swarm.topics()) {
  console.log(discovery.topic.toString('hex'))
}
```

#### `peerInfo.prioritized`

If true, the swarm will rapidly attempt to reconnect to this peer.

#### `peerInfo.ban(banStatus = false)`

Ban or unban the peer. Banning will prevent any future reconnection attempts, but it will not close any existing connections.

| Parameter | Default |
| --- | --- |
| `banStatus` | `false` |

Banning prevents future reconnection attempts, but it does not close an already-open connection.

## Types

### HyperswarmOptions

Options for constructing a Hyperswarm instance.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `keyPair` | `object` | — | A Noise keypair used to listen/connect on the DHT. Defaults to a new key pair. |
| `seed` | [`Buffer`](https://nodejs.org/api/buffer.html#class-buffer) | — | A unique 32-byte random seed used to deterministically generate the key pair. |
| `maxPeers` | `number` | `64` | Maximum number of peer connections to allow. |
| `maxClientConnections` | `number` | `Infinity` | Maximum number of outgoing (client) connections. |
| `maxServerConnections` | `number` | `Infinity` | Maximum number of incoming (server) connections. |
| `maxParallel` | `number` | `3` | Maximum number of parallel connection attempts. |
| `firewall` | `Function` | — | Sync function `(remotePublicKey) => boolean`. Return true to reject a connection. |
| `dht` | `object` | — | An existing HyperDHT instance. Defaults to creating a new one. |
| `bootstrap` | [`Array`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array) | — | Bootstrap nodes passed to the HyperDHT instance. |
| `relayThrough` | `Function\|object` | — | A relay peer or function `(force, swarm) => peer` for connection relaying. |

### JoinOptions

Options for `swarm.join()`.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `server` | `boolean` | `true` | Announce the local keypair to the DHT, accepting incoming connections for this topic. |
| `client` | `boolean` | `true` | Actively search for and connect to servers announcing this topic. |
| `limit` | `number` | `Infinity` | Maximum number of connections to establish for this topic. |

### DestroyOptions

Options for `swarm.destroy()`.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `force` | `boolean` | `false` | Force destroy even if already destroyed, skipping graceful cleanup. |

### SuspendOptions

Options for `swarm.suspend()` and `swarm.resume()`.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `log` | `Function` | — | Logging function called with progress messages. Defaults to a no-op. |
