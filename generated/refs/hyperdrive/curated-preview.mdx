<Status level="stable" />

`Hyperdrive` stores filesystem metadata in a [Hyperbee](/reference/building-blocks/hyperbee) and file contents in a blob store, typically backed by one [Corestore](/reference/helpers/corestore). Use this page for the instance surface; use the linked how-to guides for end-to-end replication flows.

<Callout type="info">
For when to choose Hyperdrive over Hyperblobs or raw Hypercore, see [From append-only logs to files](/explanation/from-logs-to-files).
</Callout>

## Install

```sh
npm i hyperdrive
```

## Quickstart

```js
import Corestore from 'corestore'
import Hyperdrive from 'hyperdrive'

const store = new Corestore('./storage')
const drive = new Hyperdrive(store)

await drive.ready()

await drive.put('/hello.txt', Buffer.from('hello world'), {
  metadata: { type: 'text/plain' }
})

const buffer = await drive.get('/hello.txt')
const entry = await drive.entry('/hello.txt')

console.log(buffer.toString())
console.log(entry?.value.metadata)

await drive.close()
```

## API Reference

### Constructor and lifecycle

#### `new Hyperdrive(store, [key])`

[src](https://github.com/holepunchto/hyperdrive/blob/v13.3.3/index.js#L21)

Creates a new Hyperdrive instance. `store` must be an instance of `Corestore`.

| Parameter | Default |
| --- | --- |
| `opts` | `{}` |

#### `await drive.ready()`

Waits until internal state is loaded.

#### `await drive.close()`

Fully close this drive, including its underlying Hypercore backed datastructures.

#### `await drive.purge()`

[src](https://github.com/holepunchto/hyperdrive/blob/v13.3.3/index.js#L377)

Purge both cores (db and blobs) from your storage, completely removing all the drive's data.

- Throws: if called on a non-main session — only the main session can be purged.

[src](https://github.com/holepunchto/hyperdrive/blob/v13.3.3/index.js#L95)

[src](https://github.com/holepunchto/hyperdrive/blob/v13.3.3/index.js#L103)

#### `drive.readable`

[src](https://github.com/holepunchto/hyperdrive/blob/v13.3.3/index.js#L107)

- Returns: Boolean indicating if we can read from this drive. After closing the drive this will be `false`.

#### `drive.version`

[src](https://github.com/holepunchto/hyperdrive/blob/v13.3.3/index.js#L99)

- Returns: Number that indicates how many modifications were made, useful as a version identifier.

#### `drive.supportsMetadata`

[src](https://github.com/holepunchto/hyperdrive/blob/v13.3.3/index.js#L33)

- Returns: Boolean indicating if the drive handles or not metadata. Always `true`.

### Files

#### `await drive.put(path, buffer, [options])`

[src](https://github.com/holepunchto/hyperdrive/blob/v13.3.3/index.js#L330)

Creates a file at `path` in the drive. `options` are the same as in `createWriteStream`.

| Parameter | Default |
| --- | --- |
| `options` | `{}` |

#### `await drive.get(path, [options])`

[src](https://github.com/holepunchto/hyperdrive/blob/v13.3.3/index.js#L316)

Reads the blob stored at `path` and resolves with its contents as a `Buffer`. Resolves with `null` when no blob exists at `path`, and also returns `null` for symbolic links.

- Returns: the blob at `path` in the drive.
- Throws: `BLOCK_NOT_AVAILABLE` if a required block is not available.

| Option | Default | Description |
| --- | --- | --- |
| `wait` | `true` | Wait for block to be downloaded |
| `timeout` | `0` | Wait at max some milliseconds (0 means no timeout) |

#### `await drive.entry(path, [options])`

[src](https://github.com/holepunchto/hyperdrive/blob/v13.3.3/index.js#L396)

Resolves with the entry stored at `path`, or `null` if no entry exists.

- Returns: the entry at `path` in the drive.
- Throws: if a symlink chain is recursive or exceeds 16 hops when `follow` is enabled.

| Option | Default |
| --- | --- |
| `seq` | `Number` |
| `key` | `String` |
| `value` | — |

#### `await drive.exists(path)`

[src](https://github.com/holepunchto/hyperdrive/blob/v13.3.3/index.js#L415)

- Returns: `true` if the entry at `path` does exists, otherwise `false`.

#### `await drive.has(path)`

[src](https://github.com/holepunchto/hyperdrive/blob/v13.3.3/index.js#L483)

Checks if path is saved to local store already.

#### `await drive.del(path)`

[src](https://github.com/holepunchto/hyperdrive/blob/v13.3.3/index.js#L340)

Deletes the file at `path` from the drive.

#### `await drive.clear(path, [options])`

[src](https://github.com/holepunchto/hyperdrive/blob/v13.3.3/index.js#L349)

Deletes the blob from storage to free up space, but the file structure reference is kept.

| Option | Default | Description |
| --- | --- | --- |
| `diff` | `false` | Returned `cleared` bytes object is null unless you enable this |

#### `await drive.clearAll([options])`

[src](https://github.com/holepunchto/hyperdrive/blob/v13.3.3/index.js#L367)

Deletes all the blobs from storage to free up space, similar to how `drive.clear()` works.

| Option | Default | Description |
| --- | --- | --- |
| `diff` | `false` | Returned `cleared` bytes object is null unless you enable this |

#### `await drive.symlink(path, linkname)`

[src](https://github.com/holepunchto/hyperdrive/blob/v13.3.3/index.js#L388)

Creates an entry in drive at `path` that points to the entry at `linkname`.

| Parameter | Default |
| --- | --- |
| `options` | `{}` |

#### `drive.createReadStream(path, [options])`

[src](https://github.com/holepunchto/hyperdrive/blob/v13.3.3/index.js#L525)

Returns a readable stream of the blob stored in the drive at `path`.

- Returns: a stream to read out the blob stored in the drive at `path`.

| Option | Default | Description |
| --- | --- | --- |
| `start` | `Number` | `start` and `end` are inclusive |
| `end` | `Number` | — |
| `length` | `Number` | `length` overrides `end`, they're not meant to be used together |
| `wait` | `true` | Wait for blocks to be downloaded |
| `timeout` | `0` | Wait at max some milliseconds (0 means no timeout) |

#### `drive.createWriteStream(path, [options])`

[src](https://github.com/holepunchto/hyperdrive/blob/v13.3.3/index.js#L579)

Stream a blob into the drive at `path`.

| Parameter | Default |
| --- | --- |
| `options` | `{}` |

| Option | Default | Description |
| --- | --- | --- |
| `executable` | `Boolean` | — |
| `metadata` | `null` | Extended file information i.e. arbitrary JSON value |

### Directories and listings

#### `drive.list(folder, [options])`

[src](https://github.com/holepunchto/hyperdrive/blob/v13.3.3/index.js#L503)

Returns a stream of all entries in the drive at paths prefixed with `folder`.

| Parameter | Default |
| --- | --- |
| `options` | `{}` |

- Returns: a stream of all entries in the drive at paths prefixed with `folder`.

| Option | Default | Description |
| --- | --- | --- |
| `recursive` | — | Whether to descend into all subfolders or not |
| `ignore` | — | Ignore files and folders by name |
| `wait` | `true` | Wait for block to be downloaded. |

#### `drive.readdir(folder, [options])`

[src](https://github.com/holepunchto/hyperdrive/blob/v13.3.3/index.js#L516)

Returns a stream of the immediate subpaths of entries stored at paths prefixed by `folder`.

- Returns: a stream of all subpaths of entries in drive stored at paths prefixed by `folder`.

| Option | Default | Description |
| --- | --- | --- |
| `wait` | `true` | Wait for block to be downloaded |

#### `await drive.entries([range], [options])`

[src](https://github.com/holepunchto/hyperdrive/blob/v13.3.3/index.js#L471)

Returns a read stream of the drive entries within the given Hyperbee `range`.

| Parameter | Description |
| --- | --- |
| `options` | `options` are the same as `Hyperbee().createReadStream([range], [options])`. |

- Returns: a read stream of entries in the drive.

#### `drive.compare(entryA, entryB)`

[src](https://github.com/holepunchto/hyperdrive/blob/v13.3.3/index.js#L344)

- Returns: `0` if entries are the same, `1` if `entryA` is older, and `-1` if `entryB` is older.

#### `drive.watch([folder])`

[src](https://github.com/holepunchto/hyperdrive/blob/v13.3.3/index.js#L419)

Returns an async iterator that watches `folder` (defaults to `/`) and yields `[current, previous]` snapshot pairs whenever the drive changes. The snapshots are auto-closed before the next value, so do not close them yourself.

- Returns: an iterator that listens on `folder` to yield changes, by default on `/`.

```js
for await (const [current, previous] of watcher) {
  console.log(current.version)
  console.log(previous.version)
}
```

#### `drive.checkout(version)`

[src](https://github.com/holepunchto/hyperdrive/blob/v13.3.3/index.js#L165)

#### `drive.diff(version, folder, [options])`

[src](https://github.com/holepunchto/hyperdrive/blob/v13.3.3/index.js#L428)

| Option | Default | Description |
| --- | --- | --- |

| `right` | `Object` | Entry in folder at drive.checkout(version) for some path |

[src](https://github.com/holepunchto/hyperdrive/blob/v13.3.3/index.js#L115)

Truncates the Hyperdrive to a previous version (both the file-structure reference and the blobs).

| Parameter | Default |
| --- | --- |
| `options` | `{}` |

- Throws: `BAD_ARGUMENT` if the truncation length is invalid.

### Replication, downloads, and blob access

#### `drive.mirror(out, [options])`

[src](https://github.com/holepunchto/hyperdrive/blob/v13.3.3/index.js#L521)

Efficiently mirror this drive into another. Returns a [`MirrorDrive`](https://github.com/holepunchto/mirror-drive#api) instance constructed with `options`.

#### `drive.download(folder, [options])`

[src](https://github.com/holepunchto/hyperdrive/blob/v13.3.3/index.js#L477)

Downloads the blobs corresponding to all entries in the drive at paths prefixed with `folder`. Returns a `Download` object that resolves once all data has been downloaded:

| Parameter | Default | Description |
| --- | --- | --- |
| `folder` | `'/'` | — |
| `options` | — | `options` are the same as those for `drive.list(folder, [options])`. |

```js
const download = await drive.download(key)
await download.done()
```

```js
download.destroy()
```

#### `await drive.downloadDiff(version, folder, [options])`

[src](https://github.com/holepunchto/hyperdrive/blob/v13.3.3/index.js#L439)

Downloads all the blobs in `folder` corresponding to entries in `drive.checkout(version)` that are not in `drive.version`. Returns a `Download` object that resolves once all data has been downloaded:

```js
const download = await drive.downloadDiff(version, folder)
await download.done()
```

```js
download.destroy()
```

#### `await drive.downloadRange(dbRanges, blobRanges)`

[src](https://github.com/holepunchto/hyperdrive/blob/v13.3.3/index.js#L453)

Downloads the entries and blobs stored in the ranges `dbRanges` and `blobRanges`. Returns a `Download` object that resolves once all data has been downloaded:

```js
const download = await drive.downloadRange(dbRanges, blobRanges)
await download.done()
```

```js
download.destroy()
```

#### `drive.findingPeers()`

[src](https://github.com/holepunchto/hyperdrive/blob/v13.3.3/index.js#L111)

Indicate to Hyperdrive that you're finding peers in the background, requests will be on hold until this is done.

#### `drive.replicate(isInitiatorOrStream)`

[src](https://github.com/holepunchto/hyperdrive/blob/v13.3.3/index.js#L147)

Creates a replication stream for the drive. Pass `true`/`false` to create a new stream as initiator/responder, or pass an existing stream or socket to replicate over it. See [`corestore.replicate`](https://github.com/holepunchto/corestore#const-stream--storereplicateoptsorstream) for how replication works.

```js
const swarm = new Hyperswarm()
const done = drive.findingPeers()
swarm.on('connection', (socket) => drive.replicate(socket))
swarm.join(drive.discoveryKey)
swarm.flush().then(done, done)
```

#### `await drive.update([options])`

[src](https://github.com/holepunchto/hyperdrive/blob/v13.3.3/index.js#L151)

Waits for initial proof of the new drive version until all `findingPeers` are done.

| Option | Default |
| --- | --- |
| `wait` | `false` |

#### `await drive.getBlobs()`

[src](https://github.com/holepunchto/hyperdrive/blob/v13.3.3/index.js#L291)

- Returns: the [Hyperblobs](https://github.com/holepunchto/hyperblobs) instance storing the blobs indexed by drive entries.

```js
await drive.put('/file.txt', Buffer.from('hi'))

const buffer1 = await drive.get('/file.txt')

const blobs = await drive.getBlobs()
const entry = await drive.entry('/file.txt')
const buffer2 = await blobs.get(entry.value.blob)

// => buffer1 and buffer2 are equals
```

#### `await drive.getBlobsLength(checkout)`

[src](https://github.com/holepunchto/hyperdrive/blob/v13.3.3/index.js#L133)

- Returns: the length of the Hyperblobs instance at the time of the specified Hyperdrive version (defaults to the current version).

## Errors

Coded errors this module can throw — catch them via `err.code`.

| Error | Thrown when |
| --- | --- |
| `BAD_ARGUMENT` | if the truncation length is invalid. |
| `BLOCK_NOT_AVAILABLE` | if a required block is not available. |
