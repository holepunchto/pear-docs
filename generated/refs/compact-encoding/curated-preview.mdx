<Status level="stable" />

`compact-encoding` packages small binary codecs behind a shared encoder interface. It is commonly paired with [Protomux](/reference/helpers/protomux) message schemas and shows up in [Hypercore](/reference/building-blocks/hypercore) and other Holepunch protocol surfaces whenever structured binary payloads matter. For the upstream package and implementation details, see the [compact-encoding repository](https://github.com/holepunchto/compact-encoding).

## Module-level encode and decode helpers

#### `const buffer = cenc.encode(enc, value)`

Encodes a single `value` using `enc` into a freshly allocated `Buffer` and returns it. Equivalent to manually creating a state, calling `enc.preencode` and `enc.encode`, and slicing the buffer — useful when you just want bytes back in one step.

| Param | Type | Description |
| --- | --- | --- |
| `enc` | `object` | Any compact-encoding encoder (for example `cenc.uint`, a custom encoder). |
| `value` | `*` | The value to encode. |

- Returns: `Buffer`

```js
const buf = cenc.encode(cenc.uint, 42)
// <Buffer 2a>
```

#### `const value = cenc.decode(enc, buffer)`

Decodes a single value from `buffer` using `enc`. Equivalent to constructing a state from the buffer and calling `enc.decode`.

| Param | Type | Description |
| --- | --- | --- |
| `enc` | `object` | Any compact-encoding encoder. |
| `buffer` | `Buffer` | The buffer to decode from. |

- Returns: The decoded value.

```js
const val = cenc.decode(cenc.uint, buf) // 42
```

## Install

```sh
npm i compact-encoding
```

## Quickstart

```js
import cenc from 'compact-encoding'

const state = cenc.state()

cenc.uint.preencode(state, 42)
cenc.string.preencode(state, 'hello')

state.buffer = Buffer.allocUnsafe(state.end)
state.start = 0

cenc.uint.encode(state, 42)
cenc.string.encode(state, 'hello')

state.start = 0

console.log(cenc.uint.decode(state))
console.log(cenc.string.decode(state))
```

## API Reference

### Encoder contract

Every bundled encoder follows the same three-method contract. The top-level helpers and exported factories below all return or consume objects with this shape.

#### `enc.preencode(state, val)`

Does a fast preencode dry-run that only sets state.end. Use this to figure out how big of a buffer you need.

#### `enc.encode(state, val)`

Writes the encoded form of the value into `state.buffer` at `state.start` (the buffer must have been preallocated via `preencode`), advancing `state.start` past the written bytes.

#### `val = enc.decode(state)`

Reads and returns a value from `state.buffer` at `state.start`, advancing `state.start` past the decoded value.

### State and convenience helpers

#### `cenc.state(start = 0, end = 0, buffer = null)`

[src](https://github.com/holepunchto/compact-encoding/blob/v3.3.0/index.js#L5)

A mutable state object `{ start, end, buffer }` used by all encoders.

| Parameter | Default | Description |
| --- | --- | --- |
| `start` | `0` | is the byte offset to start encoding/decoding at. |
| `end` | `0` | is the byte offset indicating the end of the buffer. |
| `buffer` | `null` | should be either a Node.js Buffer or Uint8Array. |

#### `cenc.from(enc)`

[src](https://github.com/holepunchto/compact-encoding/blob/v3.3.0/index.js#L966)

Coerces `encLike` — an existing compact encoder, a named raw string encoding such as `'utf8'` or `'json'`, a codec with `encode`/`decode`, or an abstract encoding with `encodingLength` — into a compact-encoding-compatible encoder object.

### Encoder factories

#### `cenc.fixed(n)`

[src](https://github.com/holepunchto/compact-encoding/blob/v3.3.0/index.js#L526)

An encoder for fixed-size buffers, where `length` is the exact byte length every encoded value must have.

#### `cenc.array(enc)`

[src](https://github.com/holepunchto/compact-encoding/blob/v3.3.0/index.js#L546)

An encoder that prefixes arrays with their length and encodes each item in order using `itemEncoding`.

#### `cenc.frame(enc)`

[src](https://github.com/holepunchto/compact-encoding/blob/v3.3.0/index.js#L566)

An encoder that prefixes one encoded payload with its byte length.

#### `cenc.record(keyEncoding, valueEncoding)`

[src](https://github.com/holepunchto/compact-encoding/blob/v3.3.0/index.js#L919)

An encoder for plain object records, with `keyEncoding` for object keys and `valueEncoding` for object values.

#### `cenc.stringRecord`

[src](https://github.com/holepunchto/compact-encoding/blob/v3.3.0/index.js#L948)

- Returns: A prebuilt `record(cenc.string, cenc.string)` encoder for simple string maps.

### Numeric encodings

#### `cenc.uint64`

[src](https://github.com/holepunchto/compact-encoding/blob/v3.3.0/index.js#L180)

- Returns: Unsigned integer encoders (`cenc.uint`, `cenc.uint8`, `cenc.uint16`, `cenc.uint24`, `cenc.uint32`, `cenc.uint40`, `cenc.uint48`, `cenc.uint56`, `cenc.uint64`). `cenc.uint` chooses a compact size automatically; the fixed-width variants always use the named byte width.

#### `cenc.int64`

[src](https://github.com/holepunchto/compact-encoding/blob/v3.3.0/index.js#L224)

- Returns: Signed integer encoders (`cenc.int`, `cenc.int8` … `cenc.int64`) built on top of the unsigned variants with ZigZag encoding.

#### `cenc.bigint`

[src](https://github.com/holepunchto/compact-encoding/blob/v3.3.0/index.js#L291)

- Returns: BigInt-aware integer encoders (`cenc.biguint64`, `cenc.bigint64`, `cenc.biguint`, `cenc.bigint`) for fixed-width or variable-width large integer values.

#### `cenc.float64`

[src](https://github.com/holepunchto/compact-encoding/blob/v3.3.0/index.js#L321)

- Returns: Floating-point encoders (`cenc.float32`, `cenc.float64`) using IEEE-754 little-endian layouts.

#### `cenc.lexint`

[src](https://github.com/holepunchto/compact-encoding/blob/v3.3.0/index.js#L293)

- Returns: The exported lexicographic integer encoder family from the `./lexint` module.

### Binary, buffer, and typed-array encodings

#### `cenc.binary`

[src](https://github.com/holepunchto/compact-encoding/blob/v3.3.0/index.js#L378)

- Returns: Buffer-oriented encoders. `buffer` length-prefixes a byte sequence, `optionalBuffer` maps zero length to `null`, and `binary` accepts either a string or buffer-like input.

#### `cenc.arraybuffer`

[src](https://github.com/holepunchto/compact-encoding/blob/v3.3.0/index.js#L390)

- Returns: An encoder for `ArrayBuffer` instances.

#### `cenc.float64array`

[src](https://github.com/holepunchto/compact-encoding/blob/v3.3.0/index.js#L459)

- Returns: Length-prefixed typed-array encoders (`cenc.uint8array`, `cenc.uint16array`, `cenc.uint32array`, `cenc.int8array`, `cenc.int16array`, `cenc.int32array`, `cenc.biguint64array`, `cenc.bigint64array`, `cenc.float32array`, `cenc.float64array`) that preserve the underlying element type.

#### `cenc.fixed64`

[src](https://github.com/holepunchto/compact-encoding/blob/v3.3.0/index.js#L544)

- Returns: Prebuilt fixed-size buffer encoders (`cenc.fixed32`, `cenc.fixed64`) for 32-byte and 64-byte values.

### Text encodings

#### `cenc.ucs2`

[src](https://github.com/holepunchto/compact-encoding/blob/v3.3.0/index.js#L511)

- Returns: String encoders for the named text encoding (`cenc.string`, `cenc.utf8`, `cenc.ascii`, `cenc.hex`, `cenc.base64`, `cenc.utf16le`, `cenc.ucs2`). Each one also exposes `.fixed(length)` for fixed-size strings.

### Boolean, date, and structured-value encodings

#### `cenc.bool`

[src](https://github.com/holepunchto/compact-encoding/blob/v3.3.0/index.js#L513)

- Returns: A one-byte boolean encoder.

#### `cenc.date`

[src](https://github.com/holepunchto/compact-encoding/blob/v3.3.0/index.js#L593)

- Returns: A `Date` encoder backed by the signed integer timestamp value from `date.getTime()`.

#### `cenc.ndjson`

[src](https://github.com/holepunchto/compact-encoding/blob/v3.3.0/index.js#L617)

- Returns: UTF-8 JSON encoders (`cenc.json`, `cenc.ndjson`). `ndjson` appends a trailing newline before encoding.

#### `cenc.none`

[src](https://github.com/holepunchto/compact-encoding/blob/v3.3.0/index.js#L630)

- Returns: A sentinel encoder that always decodes to `null` and writes no payload bytes.

#### `cenc.any`

[src](https://github.com/holepunchto/compact-encoding/blob/v3.3.0/index.js#L708)

- Returns: A schemaless tagged-value encoder for JSON-like values, arrays, objects, dates, strings, buffers, booleans, integers, and floats.

### Network encodings

#### `cenc.port`

[src](https://github.com/holepunchto/compact-encoding/blob/v3.3.0/index.js#L726)

- Returns: The same encoder as `cenc.uint16`, provided for protocol readability when encoding network ports.

#### `cenc.ip`

[src](https://github.com/holepunchto/compact-encoding/blob/v3.3.0/index.js#L880)

- Returns: Encoders for IPv4 addresses, IPv6 addresses, or either family with an embedded family tag (`cenc.ipv4`, `cenc.ipv6`, `cenc.ip`).

#### `cenc.ipAddress`

[src](https://github.com/holepunchto/compact-encoding/blob/v3.3.0/index.js#L900)

- Returns: Address-object encoders (`cenc.ipv4Address`, `cenc.ipv6Address`, `cenc.ipAddress`) for `{ host, family?, port }` shapes.

### Raw variants

#### `cenc.raw`

[src](https://github.com/holepunchto/compact-encoding/blob/v3.3.0/index.js#L9)

- Returns: A namespace of non-length-prefixed variants for many buffer, string, array, JSON, and typed-array encodings such as `cenc.raw.buffer`, `cenc.raw.utf8`, `cenc.raw.array(enc)`, and `cenc.raw.json`.
