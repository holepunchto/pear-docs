## Usage

You can either make a secret stream from an existing transport stream.

```js
const SecretStream = require('@hyperswarm/secret-stream')

const a = new SecretStream(true, tcpClientStream)
const b = new SecretStream(false, tcpServerStream)

// pipe the underlying rawstreams together

a.write(Buffer.from('hello encrypted!'))

b.on('data', function (data) {
  console.log(data) // <Buffer hello encrypted!>
})
```

Or by making your own pipeline

```js
const a = new SecretStream(true)
const b = new SecretStream(false)

// pipe the underlying rawstreams together
a.rawStream.pipe(b.rawStream).pipe(a.rawStream)

a.write(Buffer.from('hello encrypted!'))

b.on('data', function (data) {
  console.log(data) // <Buffer hello encrypted!>
})
```

## API Reference

### Constructor

#### `const s = new SecretStream(isInitiator, [rawStream], [options])`

Make a new stream. `isInitiator` is a boolean indication whether you are the client or the server. `rawStream` can be set to an underlying transport stream you want to run the noise stream over.

**Parameters:**

- `isInitiator` — `isInitiator` is a boolean indication whether you are the client or the server.
- `rawStream` _(optional)_ — `rawStream` can be set to an underlying transport stream you want to run the noise stream over.

[Source](https://github.com/holepunchto/hyperswarm-secret-stream/blob/v6.9.1/index.js#L16)

```js
{
  pattern: 'XX', // which noise pattern to use
  remotePublicKey, // set if your handshake requires it
  keyPair: { publicKey, secretKey },
  handshake: { // if you want to use an handshake performed elsewhere pass it here
    tx,
    rx,
    hash,
    publicKey,
    remotePublicKey
  },
  enableSend: true // (advanced) set false to disable the send API
}
```

### Methods

#### `s.setTimeout(ms)`

Set the stream timeout. If no data is received within a `ms` window, the stream is auto destroyed.

**Parameters:**

- `ms` — If no data is received within a `ms` window, the stream is auto destroyed.

[Source](https://github.com/holepunchto/hyperswarm-secret-stream/blob/v6.9.1/index.js#L93)

#### `s.setKeepAlive(ms)`

Send a heartbeat (empty message) every time the socket is idle for `ms` milliseconds. Note: If one side calls `s.setKeepAlive()` and the other does not, then the empty messages will be passed through to the piped stream.

**Parameters:**

- `ms` — Send a heartbeat (empty message) every time the socket is idle for `ms` milliseconds.

[Source](https://github.com/holepunchto/hyperswarm-secret-stream/blob/v6.9.1/index.js#L105)

#### `s.sendKeepAlive()`

A convenience method that sends an empty message.

[Source](https://github.com/holepunchto/hyperswarm-secret-stream/blob/v6.9.1/index.js#L118)

#### `s.start(rawStream, [options])`

Start a SecretStream from a rawStream asynchrously.

**Parameters:**

- `rawStream` — Start a SecretStream from a rawStream asynchrously.

[Source](https://github.com/holepunchto/hyperswarm-secret-stream/blob/v6.9.1/index.js#L123)

```js
const s = new SecretStream({
  autoStart: false // call start manually
})

// ... do async stuff or destroy the stream

s.start(rawStream, {
  ... options from above
})
```

#### `await s.send(buffer)`

Sends an encrypted unordered message, see [udx-native](https://github.com/holepunchto/udx-native/tree/main?tab=readme-ov-file#await-streamsendbuffer) for details.This method with silently fail if called before handshake is complete or if the underlying rawStream is not an UDX-stream (not capable of UDP).

[Source](https://github.com/holepunchto/hyperswarm-secret-stream/blob/v6.9.1/index.js#L564)

#### `s.trySend(buffer)`

Same as `send(buffer)` but does not return a promise.

**Parameters:**

- `buffer` — Same as `send(buffer)` but does not return a promise.

[Source](https://github.com/holepunchto/hyperswarm-secret-stream/blob/v6.9.1/index.js#L572)

#### `keyPair = SecretStream.keyPair([seed])`

Generate a ed25519 key pair.

#### `s.on('connect', onconnect)`
