<Status level="stable" />

`Secretstream` wraps a transport stream in a Noise handshake plus libsodium `secretstream` encryption. It is the encrypted stream layer used underneath [Hyperswarm](/reference/building-blocks/hyperswarm) and related peer transports. For the upstream package, source, and release notes, see the [@hyperswarm/secret-stream repository](https://github.com/holepunchto/hyperswarm-secret-stream).

## Install

```sh
npm i hyperswarm-secret-stream
```

## Quickstart

```js
import SecretStream from '@hyperswarm/secret-stream'

const a = new SecretStream(true)
const b = new SecretStream(false)

a.rawStream.pipe(b.rawStream).pipe(a.rawStream)

a.write(Buffer.from('hello encrypted world'))

b.on('data', (data) => {
  console.log(data.toString())
})
```

## API Reference

### Constructor and lifecycle

#### `const s = new SecretStream(isInitiator, [rawStream], [options])`

[API definition on GitHub](https://github.com/holepunchto/hyperswarm-secret-stream/blob/v6.9.1/index.js#L63)

Make a new stream. `isInitiator` is a boolean indication whether you are the client or the server. `rawStream` can be set to an underlying transport stream you want to run the noise stream over.

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `isInitiator` | `boolean` | — |  |
| `rawStream` | `object` | — |  |
| `opts` | [`SecretStreamOptions`](#secretstreamoptions) | `{}` | Options |

| Option | Default | Description |
| --- | --- | --- |
| `pattern` | `'XX'` | which noise pattern to use |
| `remotePublicKey` | — | set if your handshake requires it |
| `keyPair` | — |  |
| `handshake` | — |  |
| `enableSend` | `true` | (advanced) set false to disable the send API |

#### `s.start(rawStream, [options])`

[API definition on GitHub](https://github.com/holepunchto/hyperswarm-secret-stream/blob/v6.9.1/index.js#L273)

Start a SecretStream from a rawStream asynchrously.

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `rawStream` | `object` | — | The underlying transport stream. If omitted, an internal stream is created and exposed as `rawStream`. |
| `opts` | [`SecretStreamOptions`](#secretstreamoptions) | `{}` | Stream options (the same shape as the constructor's). |

- Returns: `void`

```js
const s = new SecretStream({
  autoStart: false // call start manually
})

// ... do async stuff or destroy the stream

s.start(rawStream, {
  ... options from above
})
```

#### `await s.flush()`

[API definition on GitHub](https://github.com/holepunchto/hyperswarm-secret-stream/blob/v6.9.1/index.js#L312)

Resolves to `true` when pending encrypted writes and the underlying raw stream have flushed successfully, or `false` if the stream closed before that happened.

- Returns: [`Promise<boolean>`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Promise) — `true` once flushed, or `false` if the stream never opened or was destroyed first.

```js
await stream.flush()
```

### Stream configuration

#### `s.setTimeout(ms)`

[API definition on GitHub](https://github.com/holepunchto/hyperswarm-secret-stream/blob/v6.9.1/index.js#L214)

Set the stream timeout. If no data is received within a `ms` window, the stream is auto destroyed.

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `ms` | `number` | — | The idle timeout in milliseconds (0 disables it). |

- Returns: `void`

```js
stream.setTimeout(15000)
```

#### `s.setKeepAlive(ms)`

[API definition on GitHub](https://github.com/holepunchto/hyperswarm-secret-stream/blob/v6.9.1/index.js#L235)

Send a heartbeat (empty message) every time the socket is idle for `ms` milliseconds. Note: If one side calls `s.setKeepAlive()` and the other does not, then the empty messages will be passed through to the piped stream.

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `ms` | `number` | — | The keep-alive interval in milliseconds (0 disables it). |

- Returns: `void`

```js
stream.setKeepAlive(5000)
```

#### `s.sendKeepAlive()`

[API definition on GitHub](https://github.com/holepunchto/hyperswarm-secret-stream/blob/v6.9.1/index.js#L254)

A convenience method that sends an empty message.

- Returns: `void`

```js
stream.sendKeepAlive()
```

### Ordered stream I/O

#### `s.write(data)`

Writes an ordered payload to be encrypted and sent through the duplex stream, returning the usual writable-stream backpressure boolean.

#### `s.end()`

Ends the stream, optionally writing a final ordered payload, following standard writable-stream behavior.

#### `s.on('data', listener)`

Receives ordered decrypted payloads as `Buffer` instances.

### Unordered messages

#### `await s.send(buffer)`

[API definition on GitHub](https://github.com/holepunchto/hyperswarm-secret-stream/blob/v6.9.1/index.js#L732)

Sends an encrypted unordered message, see [udx-native](https://github.com/holepunchto/udx-native/tree/main?tab=readme-ov-file#await-streamsendbuffer) for details.This method with silently fail if called before handshake is complete or if the underlying rawStream is not an UDX-stream (not capable of UDP).

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `buffer` | [`Buffer`](https://nodejs.org/api/buffer.html#class-buffer) | — | The message to encrypt and send. |

- Returns: [`Promise<void>`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Promise) — Resolves once the message has been sent.

```js
await stream.send(Buffer.from('ping'))
```

#### `s.trySend(buffer)`

[API definition on GitHub](https://github.com/holepunchto/hyperswarm-secret-stream/blob/v6.9.1/index.js#L747)

Same as `send(buffer)` but does not return a promise.

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `buffer` | [`Buffer`](https://nodejs.org/api/buffer.html#class-buffer) | — | The message to encrypt and send. |

- Returns: `void`

```js
stream.trySend(Buffer.from('ping'))
```

#### `s.on('message', onmessage)`

[API definition on GitHub](https://github.com/holepunchto/hyperswarm-secret-stream/blob/v6.9.1/index.js#L775)

Emmitted when an unordered message is received

### Utility methods

#### `s.alloc(len)`

[API definition on GitHub](https://github.com/holepunchto/hyperswarm-secret-stream/blob/v6.9.1/index.js#L788)

Returns a writable payload slice backed by a preallocated encrypted output buffer. Write into it, then pass it to `stream.write(...)`.

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `len` | `number` | — | The number of plaintext bytes to allocate. |

- Returns: [`Buffer`](https://nodejs.org/api/buffer.html#class-buffer) — A writable buffer of `len` bytes to fill and then `write()`.

```js
const buf = stream.alloc(4)
buf.write('ping')
stream.write(buf)
```

#### `s.toJSON()`

[API definition on GitHub](https://github.com/holepunchto/hyperswarm-secret-stream/blob/v6.9.1/index.js#L802)

Returns a diagnostic object containing connection state, keys, and any serializable raw-stream metadata.

- Returns: `object` — A snapshot with `isInitiator`, `publicKey`, `remotePublicKey`, `connected`, `destroying`, `destroyed`, and `rawStream`.

```js
console.log(JSON.stringify(stream))
```

### Static helpers

#### `keyPair = SecretStream.keyPair([seed])`

Generate a ed25519 key pair.

#### `NoiseSecretStream.id(handshakeHash, isInitiator, id)`

[API definition on GitHub](https://github.com/holepunchto/hyperswarm-secret-stream/blob/v6.9.1/index.js#L202)

Derives a 32-byte stream identity from the completed handshake hash, choosing the initiator/responder namespace via `isInitiator`.

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `handshakeHash` | [`Buffer`](https://nodejs.org/api/buffer.html#class-buffer) | — | The handshake hash to derive the |
| `isInitiator` | `boolean` | — | Whether to derive the initiator's |
| `id` | [`Buffer`](https://nodejs.org/api/buffer.html#class-buffer) | — | Optional 32-byte buffer to write the id into; a new one is allocated when omitted. |

- Returns: [`Buffer`](https://nodejs.org/api/buffer.html#class-buffer) — The 32-byte stream id.

```js
const id = SecretStream.id(stream.handshakeHash, stream.isInitiator)
```

[API definition on GitHub](https://github.com/holepunchto/hyperswarm-secret-stream/blob/v6.9.1/index.js#L674)

## Types

### Handshake

A precomputed Noise handshake to reuse instead of performing one over the
stream. Pass it as `opts.handshake` to adopt the result of a handshake done
elsewhere.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `tx` | [`Buffer`](https://nodejs.org/api/buffer.html#class-buffer) | — | The transmit (encryption) session key. |
| `rx` | [`Buffer`](https://nodejs.org/api/buffer.html#class-buffer) | — | The receive (decryption) session key. |
| `hash` | [`Buffer`](https://nodejs.org/api/buffer.html#class-buffer) | — | The unique hash of the handshake. |
| `publicKey` | [`Buffer`](https://nodejs.org/api/buffer.html#class-buffer) | — | The local public key used in the handshake. |
| `remotePublicKey` | [`Buffer`](https://nodejs.org/api/buffer.html#class-buffer) | — | The remote peer's public key. |

### KeyPair

An ed25519 key pair, as produced by \{@link NoiseSecretStream.keyPair\}.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `publicKey` | [`Buffer`](https://nodejs.org/api/buffer.html#class-buffer) | — | The 32-byte public key. |
| `secretKey` | [`Buffer`](https://nodejs.org/api/buffer.html#class-buffer) | — | The 64-byte secret key. |

### SecretStreamOptions

Options for creating a `SecretStream` (also accepted by `start()`).

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `pattern` | `string` | `XX` | Which Noise handshake pattern to use. |
| `remotePublicKey` | [`Buffer`](https://nodejs.org/api/buffer.html#class-buffer) | — | The remote peer's public key, set if the handshake pattern requires it. |
| `keyPair` | [`KeyPair\|Promise<KeyPair>`](#keypair) | — | The local key pair, or a promise resolving to one (the stream waits for it and auto-destroys if it errors). |
| `handshake` | [`Handshake`](#handshake) | — | A handshake performed elsewhere to adopt instead of handshaking over the stream. |
| `keepAlive` | `number` | `0` | Send a keep-alive (empty message) when idle for this many milliseconds (0 disables). |
| `autoStart` | `boolean` | `true` | Start the stream automatically; set false to call `start()` manually. |
| `enableSend` | `boolean` | `true` | (advanced) Set false to disable the unordered send API. |
