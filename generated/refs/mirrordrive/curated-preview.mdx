<Status level="stable" />

`Mirrordrive` computes diffs between two drive-like APIs and applies them efficiently. It is the helper that powers sync flows between [Hyperdrive](/reference/building-blocks/hyperdrive) and [Localdrive](/reference/helpers/localdrive), including the `drive.mirror(...)` shortcut on Hyperdrive. A `MirrorDrive` instance is itself an async iterator, so iterating it with `for await (const diff of mirror)` drives the diff/copy pass and yields one diff object per entry. For source and release notes, see the [mirror-drive repository](https://github.com/holepunchto/mirror-drive).

## Option patterns

#### `transformers`

[API definition on GitHub](https://github.com/holepunchto/mirror-drive/blob/v1.14.2/index.js#L88)
- Returns: A copy pipeline hook. Each transformer is a function `(key) => stream | null`; returning `null` skips that transform for the current file.
- Example:

```js
const mirror = new MirrorDrive(src, dst, {
  transformers: [
    (key) => key.endsWith('.txt') ? myTransformStream() : null
  ]
})
```

#### `entries`

[API definition on GitHub](https://github.com/holepunchto/mirror-drive/blob/v1.14.2/index.js#L87)
- Returns: A fixed list of entries to mirror instead of reading them from `src.list(...)`. When this option is used, `prefix` is ignored.
- Example:

```js
const entries = [{ key: '/index.html' }, { key: '/styles.css' }]
const mirror = new MirrorDrive(src, dst, { entries })
```

#### `metadataEquals`

[API definition on GitHub](https://github.com/holepunchto/mirror-drive/blob/v1.14.2/index.js#L85)
- Returns: A predicate used to decide whether metadata changes should count as a diff when both drives support metadata.
- Example:

```js
const mirror = new MirrorDrive(src, dst, {
  metadataEquals(left, right) {
    return JSON.stringify(left) === JSON.stringify(right)
  }
})
```

## Install

```sh
npm i mirror-drive
```

## Quickstart

```js
import Corestore from 'corestore'
import Hyperdrive from 'hyperdrive'
import Localdrive from 'localdrive'
import MirrorDrive from 'mirror-drive'

const store = new Corestore('./storage')
const src = new Localdrive('./site')
const dst = new Hyperdrive(store)

await dst.ready()

const mirror = new MirrorDrive(src, dst, { prune: true })

for await (const diff of mirror) {
  console.log(diff)
}
```

## API Reference

### Constructor and lifecycle

#### `const mirror = new MirrorDrive(src, dst, [options])`

[API definition on GitHub](https://github.com/holepunchto/mirror-drive/blob/v1.14.2/index.js#L107)

Creates a mirror instance to efficiently move `src` drive into `dst` drive.

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `src` | [`Hyperdrive\|Localdrive`](/reference/building-blocks/hyperdrive) | — | Source drive to read from. |
| `dst` | [`Hyperdrive\|Localdrive`](/reference/building-blocks/hyperdrive) | — | Destination drive to write into (must be writable). |
| `opts` | [`MirrorDriveOptions`](#mirrordriveoptions) | `{}` | Mirror options. |

| Option | Default | Description |
| --- | --- | --- |
| `prefix` | `'/'` |  |
| `dryRun` | `false` |  |
| `prune` | `true` |  |
| `includeEquals` | `false` |  |
| `filter` | — |  |
| `metadataEquals` | — |  |
| `batch` | `false` |  |
| `entries` | `null` | Array of key entries (if you use this then prefix is ignored) |
| `ignore` | — | Ignore source files and folders by name. |
| `transformers` | — | Array of factory functions (key) => stream |

#### `await mirror.done()`

[API definition on GitHub](https://github.com/holepunchto/mirror-drive/blob/v1.14.2/index.js#L234)

It starts processing all the diffing until is done.

- Returns: [`Promise<void>`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Promise) — Resolves when all diffs have been processed.

```js
const mirror = new MirrorDrive(src, dst)
await mirror.done()
console.log(mirror.count) // { files: 3, add: 2, remove: 0, change: 1 }
```

### Mirror state

#### `mirror.count`

[API definition on GitHub](https://github.com/holepunchto/mirror-drive/blob/v1.14.2/index.js#L133)

It counts the total files proccessed, added, removed, and changed.

- Returns: `{ files: number, add: number, remove: number, change: number }`

#### `mirror.bytesAdded`

[API definition on GitHub](https://github.com/holepunchto/mirror-drive/blob/v1.14.2/index.js#L143)

The total number of bytes copied into the destination so far.

- Returns: `number`

#### `mirror.bytesRemoved`

[API definition on GitHub](https://github.com/holepunchto/mirror-drive/blob/v1.14.2/index.js#L138)

The total number of bytes removed from the destination so far.

- Returns: `number`

#### `mirror.finished`

[API definition on GitHub](https://github.com/holepunchto/mirror-drive/blob/v1.14.2/index.js#L149)

`true` once the mirror pass has completed.

- Returns: `boolean`

#### `mirror.preloaded`

[API definition on GitHub](https://github.com/holepunchto/mirror-drive/blob/v1.14.2/index.js#L120)

`true` once any configured preload phase has finished fetching the blob ranges or block maps it needs.

- Returns: `boolean`

#### `mirror.peers`

[API definition on GitHub](https://github.com/holepunchto/mirror-drive/blob/v1.14.2/index.js#L189)

The source drive's current peer list when `src.core` exists, otherwise an empty array.

- Returns: [`Array<object>`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array)

#### `mirror.downloadProgress`

[API definition on GitHub](https://github.com/holepunchto/mirror-drive/blob/v1.14.2/index.js#L199)

A `0..1` estimate of preload/download progress when progress tracking is enabled.

- Returns: `number`

#### `mirror.downloadedBlocks`

[API definition on GitHub](https://github.com/holepunchto/mirror-drive/blob/v1.14.2/index.js#L155)

The number of blob blocks downloaded from the source during the current run.

- Returns: `number`

#### `mirror.downloadedBytes`

[API definition on GitHub](https://github.com/holepunchto/mirror-drive/blob/v1.14.2/index.js#L161)

The number of blob bytes downloaded from the source during the current run.

- Returns: `number`

#### `mirror.uploadedBlocks`

[API definition on GitHub](https://github.com/holepunchto/mirror-drive/blob/v1.14.2/index.js#L168)

The number of destination blob blocks uploaded or written during the current run.

- Returns: `number`

#### `mirror.uploadedBytes`

[API definition on GitHub](https://github.com/holepunchto/mirror-drive/blob/v1.14.2/index.js#L173)

The number of destination blob bytes uploaded or written during the current run.

- Returns: `number`

### Monitoring progress

#### `mirror.monitor(opts)`

[API definition on GitHub](https://github.com/holepunchto/mirror-drive/blob/v1.14.2/index.js#L218)

A monitor object that emits progress updates and exposes the latest `stats` snapshot.

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `opts` | [`MonitorOptions`](#monitoroptions) | — | Monitor options. |

- Returns: [`Monitor`](/reference/helpers/mirrordrive) — A new monitor instance attached to this mirror.

```js
const monitor = mirror.monitor({ interval: 500 })
monitor.on('update', (stats) => {
  console.log('downloaded', stats.download.bytes, 'bytes')
})
```

#### `monitor.stats`

[API definition on GitHub](https://github.com/holepunchto/mirror-drive/blob/v1.14.2/index.js#L19)
- Returns: The most recent immutable stats snapshot, shaped like:
  `{
    peers,
    download: { bytes, blocks, speed, progress },
    upload: { bytes, blocks, speed }
  }`

#### `mirror.preloaded`

[API definition on GitHub](https://github.com/holepunchto/mirror-drive/blob/v1.14.2/index.js#L120)

`true` once any configured preload phase has finished fetching the blob ranges or block maps it needs.

- Returns: `boolean`

#### `monitor.destroyed`

[API definition on GitHub](https://github.com/holepunchto/mirror-drive/blob/v1.14.2/index.js#L29)
- Returns: `true` after the monitor has been torn down.

#### `monitor.destroy()`

[API definition on GitHub](https://github.com/holepunchto/mirror-drive/blob/v1.14.2/index.js#L55)

Stops update polling and detaches the monitor from the mirror.

#### `monitor.on('update', stats)`

[API definition on GitHub](https://github.com/holepunchto/mirror-drive/blob/v1.14.2/index.js#L52)

Emitted every `interval` milliseconds with the latest `monitor.stats` snapshot.

#### `monitor.on('preloaded', listener)`

[API definition on GitHub](https://github.com/holepunchto/mirror-drive/blob/v1.14.2/index.js#L290)

Emitted once preload has completed.

#### `monitor.on('destroy', listener)`

[API definition on GitHub](https://github.com/holepunchto/mirror-drive/blob/v1.14.2/index.js#L67)

Emitted when `monitor.destroy()` runs or when the parent mirror finishes and cleans up remaining monitors.

## Types

### MirrorDriveOptions

Options for controlling how `MirrorDrive` synchronises drives.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `prefix` | [`string\|Array<string>`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array) | `'/'` | One or more path prefixes to mirror. When an array, each prefix is mirrored in order. |
| `dryRun` | `boolean` | `false` | Walk the diff and emit events without writing any changes to `dst`. |
| `prune` | `boolean` | `true` | Remove files from `dst` that no longer exist in `src`. |
| `includeEquals` | `boolean` | `false` | Emit `{ op: 'equal' }` events for files that are identical in both drives. |
| `filter` | `function(string): boolean` | — | Called with each source key; return `false` to skip that entry. |
| `metadataEquals` | `function(*,*): boolean` | — | Custom equality check for file metadata; receives `(srcMetadata, dstMetadata)`. |
| `batch` | `boolean` | `false` | Accumulate destination writes in a single batch and flush at the end. |
| `entries` | [`Array<object>\|null`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array) | `null` | Pre-computed list of source entries to mirror; when provided, `prefix` is ignored. |
| `ignore` | [`string\|Array<string>`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array) | — | Path(s) to exclude from the source listing. |
| `transformers` | [`Array<function>`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array) | `[` | ] - Array of factory functions `(key) => stream \| null`; each returned stream is piped between source read and destination write. |
| `progress` | `boolean` | `false` | Enable download/upload progress tracking (requires `src.getBlobs`). |
| `dedup` | `boolean` | `false` | Enable content-addressed deduplication using Rabin chunking on the destination. |

### MonitorOptions

Options for the `monitor()` method.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `interval` | `number` | `250` | How often (in milliseconds) the monitor emits `update` events with fresh stats. |
