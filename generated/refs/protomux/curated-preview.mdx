<Status level="stable" />

`Protomux` multiplexes multiple message-oriented subprotocols over one framed stream. It is typically layered on top of [Secretstream](/p2p/reference/helpers/secretstream) and uses [Compact encoding](/p2p/reference/helpers/compact-encoding) for message schemas. For source and releases, see the [Protomux repository](https://github.com/holepunchto/protomux).

## Install

```sh
npm i protomux
```

## Quickstart

```js
import Protomux from 'protomux'
import cenc from 'compact-encoding'

const mux = new Protomux(aFramedEncryptedStream)

const channel = mux.createChannel({
  protocol: 'chat',
  onopen() {
    console.log('chat channel opened')
  }
})

const message = channel.addMessage({
  encoding: cenc.string,
  onmessage(text) {
    console.log(text)
  }
})

channel.open()
message.send('hello')
```

## API Reference

### Constructor and mux helpers

#### `mux = new Protomux(stream, [options])`

[src](https://github.com/holepunchto/protomux/blob/v3.12.0/index.js#L332)

Make a new instance. `stream` should be a framed stream, preserving the messages written.

| Parameter | Default |
| --- | --- |
| `options` | `{}` |

```js
{
  // Called when the muxer wants to allocate a message that is written, defaults to Buffer.allocUnsafe.
  alloc (size) {}
}
```

#### `mux = Protomux.from(stream | muxer, [options])`

[src](https://github.com/holepunchto/protomux/blob/v3.12.0/index.js#L366)

Helper to accept either an existing muxer instance or a stream (which creates a new one).

#### `Protomux.isProtomux(mux)`

[src](https://github.com/holepunchto/protomux/blob/v3.12.0/index.js#L372)

Returns `true` when `value` looks like a Protomux instance.

#### `mux.cork()`

[src](https://github.com/holepunchto/protomux/blob/v3.12.0/index.js#L386)

Same as `channel.cork` but on the muxer instance.

#### `mux.uncork()`

[src](https://github.com/holepunchto/protomux/blob/v3.12.0/index.js#L393)

Same as `channel.uncork` but on the muxer instance.

#### `mux.isIdle()`

[src](https://github.com/holepunchto/protomux/blob/v3.12.0/index.js#L382)

Convenience method that returns true if the number of channels is currently 0.

#### `for (const channel of muxer) { ... }`

The muxer instance is iterable, so you can iterate over all the channels.

### Pairing and channel discovery

#### `mux.pair({ protocol, id }, callback)`

[src](https://github.com/holepunchto/protomux/blob/v3.12.0/index.js#L408)

Register a callback to be called everytime a new channel is requested.

#### `mux.unpair({ protocol, id })`

[src](https://github.com/holepunchto/protomux/blob/v3.12.0/index.js#L412)

Unregisters the pair callback.

#### `mux.opened({ protocol, id })`

[src](https://github.com/holepunchto/protomux/blob/v3.12.0/index.js#L416)

Boolean that indicates if the channel is opened.

#### `mux.getLastChannel(options)`

[src](https://github.com/holepunchto/protomux/blob/v3.12.0/index.js#L401)

Returns the most recently opened matching channel, or `null` if none is open.

### Creating channels

#### `mux.createChannel(opts)`

[src](https://github.com/holepunchto/protomux/blob/v3.12.0/index.js#L422)

Add a new protocol channel.

| Option | Default |
| --- | --- |
| `protocol` | `'name of the protocol'` |
| `id` | `buffer` |
| `handshake` | `encoding` |
| `messages` | — |

#### `mux.stream`

[src](https://github.com/holepunchto/protomux/blob/v3.12.0/index.js#L336)

- Returns: The framed transport stream backing this mux.

#### `mux.drained`

[src](https://github.com/holepunchto/protomux/blob/v3.12.0/index.js#L338)

### Channel lifecycle

#### `channel.open([handshake])`

[src](https://github.com/holepunchto/protomux/blob/v3.12.0/index.js#L87)

Open the channel.

#### `channel.fullyOpened()`

[src](https://github.com/holepunchto/protomux/blob/v3.12.0/index.js#L66)

Resolves to `true` when the channel fully opens or `false` if it closes first.

#### `channel.fullyClosed()`

[src](https://github.com/holepunchto/protomux/blob/v3.12.0/index.js#L77)

Resolves once the channel has been destroyed and all pending async handlers have finished.

#### `channel.close()`

[src](https://github.com/holepunchto/protomux/blob/v3.12.0/index.js#L243)

Closes the protocol channel.

#### `channel.cork()`

[src](https://github.com/holepunchto/protomux/blob/v3.12.0/index.js#L235)

Corking the protocol channel, makes it buffer messages and send them all in a batch when it uncorks.

#### `channel.uncork()`

[src](https://github.com/holepunchto/protomux/blob/v3.12.0/index.js#L239)

Uncork and send the batch.

[src](https://github.com/holepunchto/protomux/blob/v3.12.0/index.js#L260)

Add/register a message type for a certain encoding. Options include:

| Option |
| --- |
| `encoding` |

#### `m.send(data)`

Send a message.

#### `m.encoding`

The encoding for this message.

#### `m.onmessage`

Function that is called when a message arrives.

### Lifecycle callbacks

#### `channel.onopen`

[src](https://github.com/holepunchto/protomux/blob/v3.12.0/index.js#L37)

- Returns: Called when the channel opens. `handshake` is the decoded open payload or `null`, and `channel` is the channel instance.

#### `channel.onclose`

[src](https://github.com/holepunchto/protomux/blob/v3.12.0/index.js#L38)

- Returns: Called when the channel closes. `isRemote` is `true` when the remote side initiated the close, and `channel` is the channel instance.

#### `channel.ondestroy`

[src](https://github.com/holepunchto/protomux/blob/v3.12.0/index.js#L39)

- Returns: Called when the channel is destroyed. `channel` is the destroyed channel instance.

#### `channel.ondrain`

[src](https://github.com/holepunchto/protomux/blob/v3.12.0/index.js#L40)

- Returns: Called when the channel's underlying mux becomes writable again. `channel` is that channel instance.
