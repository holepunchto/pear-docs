<Status level="stable" />

`Corestore` manages many related [Hypercores](/reference/building-blocks/hypercore) behind one storage root and one replication surface. It is the helper you usually share across [Hyperbee](/reference/building-blocks/hyperbee), [Hyperdrive](/reference/building-blocks/hyperdrive), and [Autobase](/reference/building-blocks/autobase) instances. For upstream source and changelog context, see the [Corestore repository](https://github.com/holepunchto/corestore).

## Install

```sh
npm i corestore
```

## Quickstart

```js
import Corestore from 'corestore'

const store = new Corestore('./app-storage')
await store.ready()

const messages = store.get({
  name: 'messages',
  valueEncoding: 'json'
})

await messages.ready()
await messages.append({ text: 'hello from corestore' })

console.log(await messages.get(0))

await store.close()
```

## API Reference

### Constructor and lifecycle

#### `new Corestore(storage, options = {})`

[src](https://github.com/holepunchto/corestore/blob/v7.12.0/index.js#L236)

Create a new Corestore instance.

| Parameter | Default | Description |
| --- | --- | --- |
| `storage` | — | can be either a `hypercore-storage` instance or a string. |
| `options` | `{}` | — |

- Throws: `ASSERTION` if `primaryKey` is set on a root store without `unsafe: true`.

| Option | Default | Description |
| --- | --- | --- |
| `primaryKey` | `null` | The primary key to use as the master key for key derivation. |
| `writable` | `true` | — |
| `treeCache` | — | Options to use when creating hypercore's default storage |

#### `await store.ready()`

A promise that resolves once the storage seed is loaded and properties such as `store.primaryKey` are available.

#### `await store.close()`

Fully close this Corestore instance.

#### `await store.suspend()`

[src](https://github.com/holepunchto/corestore/blob/v7.12.0/index.js#L351)

Suspend the underlying storage for the Corestore.

| Parameter | Default |
| --- | --- |
| `options` | `{}` |

#### `await store.resume()`

[src](https://github.com/holepunchto/corestore/blob/v7.12.0/index.js#L358)

Resume a suspended Corestore.

### Store properties

#### `store.storage`

[src](https://github.com/holepunchto/corestore/blob/v7.12.0/index.js#L240)

- Returns: The backing storage adapter used for aliases, seeds, and Hypercore data files.

#### `store.primaryKey`

[src](https://github.com/holepunchto/corestore/blob/v7.12.0/index.js#L255)

- Returns: The 32-byte primary key used to deterministically derive writable named cores and namespaced key pairs.

#### `store.readOnly`

[src](https://github.com/holepunchto/corestore/blob/v7.12.0/index.js#L253)

- Returns: `true` when the store was opened without write access.

#### `store.manifestVersion`

[src](https://github.com/holepunchto/corestore/blob/v7.12.0/index.js#L257)

- Returns: The Hypercore manifest version used when Corestore creates new writable cores.

#### `store.active`

[src](https://github.com/holepunchto/corestore/blob/v7.12.0/index.js#L259)

- Returns: `true` when the store should automatically attach loaded cores to active replication streams.

### Loading cores and scoping sessions

#### `store.get(key | { name: 'a-name', ...hypercoreOpts})`

[src](https://github.com/holepunchto/corestore/blob/v7.12.0/index.js#L559)

Loads a Hypercore, either by name (if the `name` option is provided), or from the provided key (if the first argument is a Buffer or String with hex/z32 key, or if the `key` options is set).

#### `storeA.session()`

Create a new Corestore session. Closing a session will close all cores made from this session.

#### `store.namespace(name)`

[src](https://github.com/holepunchto/corestore/blob/v7.12.0/index.js#L372)

Create a new namespaced Corestore session. Namespacing is useful if you're going to be sharing a single Corestore instance between many applications or components, as it prevents name collisions.

```js
const ns1 = store.namespace('a')
const ns2 = ns1.namespace('b')
const core1 = ns1.get({ name: 'main' }) // These will load different Hypercores
const core2 = ns2.get({ name: 'main' })
```

### Replication and discovery

#### `store.replicate(optsOrStream)`

[src](https://github.com/holepunchto/corestore/blob/v7.12.0/index.js#L476)

Creates a replication stream that's capable of replicating all Hypercores that are managed by the Corestore, assuming the remote peer has the correct capabilities.

```js
const swarm = new Hyperswarm()

// join the relevant topic
swarm.join(...)

// simply pass the connection stream to corestore
swarm.on('connection', (connection) => store.replicate(connection))
```

#### `store.findingPeers()`

[src](https://github.com/holepunchto/corestore/blob/v7.12.0/index.js#L336)

A completion callback. Call it after the current peer-discovery pass finishes so pending update waits on loaded cores can unblock.

#### `store.list(namespace)`

[src](https://github.com/holepunchto/corestore/blob/v7.12.0/index.js#L379)

Creates a discovery key stream of all cores within a namespace or all cores in general if no namespace is provided.

#### `store.getAuth(discoveryKey)`

[src](https://github.com/holepunchto/corestore/blob/v7.12.0/index.js#L383)

The storage-layer auth metadata for that core, including manifest details when available.

### Key derivation and maintenance

#### `await store.createKeyPair(name, ns = this.ns)`

[src](https://github.com/holepunchto/corestore/blob/v7.12.0/index.js#L616)

Generate a key pair seeded with the Corestore's primary key using a `name` and a `ns` aka namespace. `ns` defaults to the current namespace.

| Parameter | Default |
| --- | --- |
| `ns` | `this.ns` |

#### `store.audit(opts = {})`

[src](https://github.com/holepunchto/corestore/blob/v7.12.0/index.js#L347)

An audit report describing the state of the backing store and any detected inconsistencies.

| Parameter | Default |
| --- | --- |
| `opts` | `{}` |

#### `await store.staticify(core, opts)`

[src](https://github.com/holepunchto/corestore/blob/v7.12.0/index.js#L515)

A reopened Hypercore whose manifest is converted into a static prologue-based manifest for the current data snapshot.

- Throws: if the core has no data to staticify.

### Watchers

#### `store.watch((core) => {})`

[src](https://github.com/holepunchto/corestore/blob/v7.12.0/index.js#L278)

Register a callback called when new Hypercores are opened. `core` is the internal core for the opened Hypercore. It can be used to create weak references to a Hypercore like so:

| Parameter | Default |
| --- | --- |
| `fn` | `> {}` |

```js
store.watch(function (core) {
  const weakCore = new Hypercore({ core, weak: true })
})
```

#### `store.unwatch(callback)`

[src](https://github.com/holepunchto/corestore/blob/v7.12.0/index.js#L287)

Unregister a callback used with `store.watch(callback)` so it no longer fires.

### Group notifications (experimental)

#### `store.notifyGroup(topic)`

[src](https://github.com/holepunchto/corestore/blob/v7.12.0/index.js#L307)

Get a `handle` for updates from all `hypercore`s with the group `topic` set.

<Callout type="warn">
Group notifications are experimental. The API is subject to change and may break in any release.
</Callout>

#### `handle.update(opts = {})`

Gets updates for the `topic` the handle is for.

| Parameter | Default |
| --- | --- |
| `opts` | `{}` |

| Option | Default | Description |
| --- | --- | --- |
| `since` | `0` | What timestamp to start returning updates from. Default `0` returns all updates |
| `reverse` | `true` | Flag to return updates in reverse order. Defaults to `true` so latest returned first |

```js
for await (const key of handle.updates()) {
  // ...
}
```

#### `handle.destroy()`

[src](https://github.com/holepunchto/corestore/blob/v7.12.0/lib/notify.js#L20)

Destroys and unregisters the `handle` from its `store`.

#### `handle.on('update', callback)`

Calls the callback whenever a core with the `topic` for the `handle` updates.

#### `store.on('group-active', (topic) => {})`

[src](https://github.com/holepunchto/corestore/blob/v7.12.0/index.js#L299)

The `group-active` event emits whenever an opened Hypercore in the store updates. The `topic` is the group topic the core belongs to.
