[`bare-url`](https://github.com/holepunchto/bare-url) — WHATWG URL implementation for JavaScript. It is a native addon.

Mirrors the Node.js [`url`](https://nodejs.org/api/url.html) module.

```sh
npm i bare-url
```

## Usage

```js
const { URL, URLSearchParams } = require('bare-url')

const url = new URL('https://example.com/path?foo=bar#hash')

console.log(url.hostname) // 'example.com'
console.log(url.pathname) // '/path'
console.log(url.searchParams.get('foo')) // 'bar'
```

To register `URL` and `URLSearchParams` as globals:

```js
require('bare-url/global')
```

## API

### URL

#### `new URL(input: string, base?: string | URL)`

<sub>[Source](https://github.com/holepunchto/bare-url/blob/v2.4.5/index.d.ts#L22)</sub>

Parse `input` as a URL. If `base` is provided, `input` is resolved relative to `base`. Throws if `input` is not a valid URL.

**Parameters**

- `input` (`string`)
- `base` (`string` | `URL`, optional)

#### `hash: string`

<sub>[Source](https://github.com/holepunchto/bare-url/blob/v2.4.5/index.d.ts#L15)</sub>

The fragment including the leading `'#'`, or an empty string.

#### `host: string`

<sub>[Source](https://github.com/holepunchto/bare-url/blob/v2.4.5/index.d.ts#L9)</sub>

The hostname and port, e.g. `'example.com:8080'`.

#### `hostname: string`

<sub>[Source](https://github.com/holepunchto/bare-url/blob/v2.4.5/index.d.ts#L10)</sub>

The hostname without the port.

#### `href: string`

<sub>[Source](https://github.com/holepunchto/bare-url/blob/v2.4.5/index.d.ts#L5)</sub>

The full serialized URL string. Setting this property reparses the URL.

#### `password: string`

<sub>[Source](https://github.com/holepunchto/bare-url/blob/v2.4.5/index.d.ts#L8)</sub>

The password portion of the URL, or an empty string.

#### `pathname: string`

<sub>[Source](https://github.com/holepunchto/bare-url/blob/v2.4.5/index.d.ts#L12)</sub>

The path portion of the URL.

#### `port: string`

<sub>[Source](https://github.com/holepunchto/bare-url/blob/v2.4.5/index.d.ts#L11)</sub>

The port as a string, or an empty string if not present.

#### `protocol: string`

<sub>[Source](https://github.com/holepunchto/bare-url/blob/v2.4.5/index.d.ts#L6)</sub>

The URL scheme followed by `':'`, e.g. `'https:'`.

#### `search: string`

<sub>[Source](https://github.com/holepunchto/bare-url/blob/v2.4.5/index.d.ts#L13)</sub>

The query string including the leading `'?'`, or an empty string.

#### `searchParams: URLSearchParams`

<sub>[Source](https://github.com/holepunchto/bare-url/blob/v2.4.5/index.d.ts#L14)</sub>

A `URLSearchParams` object for the query string. Mutations to the params are reflected in the URL.

#### `URL.toJSON(): string`

<sub>[Source](https://github.com/holepunchto/bare-url/blob/v2.4.5/index.d.ts#L18)</sub>

Returns the serialized string form. Suitable for JSON serialization.

#### `URL.toString(): string`

<sub>[Source](https://github.com/holepunchto/bare-url/blob/v2.4.5/index.d.ts#L17)</sub>

Returns the serialized string form.

#### `URL.canParse(input: string, base?: string | URL): boolean`

<sub>[Source](https://github.com/holepunchto/bare-url/blob/v2.4.5/index.d.ts#L32)</sub>

Return `true` if `input` can be parsed as a valid URL, optionally relative to `base`.

**Parameters**

- `input` (`string`)
- `base` (`string` | `URL`, optional)

#### `URL.fileURLToPath(url: URL | string): string`

<sub>[Source](https://github.com/holepunchto/bare-url/blob/v2.4.5/index.d.ts#L34)</sub>

Convert a `file:` URL to a platform-specific file path. `url` may be a `URL` instance or a string. Throws if the URL does not use the `file:` protocol or contains invalid path characters.

**Parameters**

- `url` (`URL` | `string`)

#### `URL.isURL(value: unknown): value is URL`

<sub>[Source](https://github.com/holepunchto/bare-url/blob/v2.4.5/index.d.ts#L26)</sub>

Return `true` if `value` is a `URL` instance.

**Parameters**

- `value` (`unknown`)

#### `URL.isURLSearchParams(value: unknown): value is URLSearchParams`

<sub>[Source](https://github.com/holepunchto/bare-url/blob/v2.4.5/index.d.ts#L28)</sub>

**Parameters**

- `value` (`unknown`)

#### `URL.parse(input: string, base?: string | URL): URL | null`

<sub>[Source](https://github.com/holepunchto/bare-url/blob/v2.4.5/index.d.ts#L30)</sub>

Parse `input` as a URL without throwing. Returns a `URL` instance on success, or `null` on failure.

**Parameters**

- `input` (`string`)
- `base` (`string` | `URL`, optional)

#### `URL.pathToFileURL(pathname: string): URL`

<sub>[Source](https://github.com/holepunchto/bare-url/blob/v2.4.5/index.d.ts#L36)</sub>

Convert a platform-specific file path to a `file:` URL.

**Parameters**

- `pathname` (`string`)

#### `username: string`

<sub>[Source](https://github.com/holepunchto/bare-url/blob/v2.4.5/index.d.ts#L7)</sub>

The username portion of the URL, or an empty string.

- `name` (`string`)
- `value` (`string`, optional)

#### `get(name: string): string | undefined`

<sub>[Source](https://github.com/holepunchto/bare-url/blob/v2.4.5/lib/url-search-params.d.ts#L6)</sub>

**Parameters**

- `name` (`string`)

<sub>[Source](https://github.com/holepunchto/bare-url/blob/v2.4.5/lib/url-search-params.d.ts#L7)</sub>

- `name` (`string`)

<sub>[Source](https://github.com/holepunchto/bare-url/blob/v2.4.5/lib/url-search-params.d.ts#L8)</sub>

Return `true` if a pair with `name` exists. If `value` is provided, the pair must also match `value`.
