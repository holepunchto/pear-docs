[`bare-bundle`](https://github.com/holepunchto/bare-bundle) — Application bundle format for JavaScript.

```sh
npm i bare-bundle
```

## API

### Bundle

#### `new Bundle(opts?: BundleOptions)`

<sub>[Source](https://github.com/holepunchto/bare-bundle/blob/v1.10.0/index.d.ts#L69)</sub>

Create an empty `Bundle`, optionally supplying a custom `File` class to back stored files.

**Parameters**

- `opts` ([`BundleOptions`](#bundleoptions), optional)

#### `addons: string[]`

<sub>[Source](https://github.com/holepunchto/bare-bundle/blob/v1.10.0/index.d.ts#L48)</sub>

The keys of files in the bundle that are native addons.

#### `assets: string[]`

<sub>[Source](https://github.com/holepunchto/bare-bundle/blob/v1.10.0/index.d.ts#L49)</sub>

The keys of files in the bundle that are non-JavaScript assets.

#### `Bundle.from(value: string | Buffer | Bundle): Bundle`

<sub>[Source](https://github.com/holepunchto/bare-bundle/blob/v1.10.0/index.d.ts#L83)</sub>

Coerce `value` — a serialized bundle string, a `Buffer`, or an existing `Bundle` — into a `Bundle`.

**Parameters**

- `value` (`string` | `Buffer` | `Bundle`)

#### `Bundle.isBundle(value: unknown): value is Bundle`

<sub>[Source](https://github.com/holepunchto/bare-bundle/blob/v1.10.0/index.d.ts#L82)</sub>

Check whether `value` is a `Bundle`.

**Parameters**

- `value` (`unknown`)

#### `Bundle.version: number`

<sub>[Source](https://github.com/holepunchto/bare-bundle/blob/v1.10.0/index.d.ts#L67)</sub>

The bundle format version this implementation produces and expects.

#### `empty(): boolean`

<sub>[Source](https://github.com/holepunchto/bare-bundle/blob/v1.10.0/index.d.ts#L55)</sub>

Check whether the bundle contains no files.

#### `exists(key: string): boolean`

<sub>[Source](https://github.com/holepunchto/bare-bundle/blob/v1.10.0/index.d.ts#L57)</sub>

Check whether a file exists at `key`.

**Parameters**

- `key` (`string`)

#### `files: Record<string, MemoryFile>`

<sub>[Source](https://github.com/holepunchto/bare-bundle/blob/v1.10.0/index.d.ts#L45)</sub>

The bundle's files, keyed by path, as `MemoryFile` instances.

#### `id: string | null`

<sub>[Source](https://github.com/holepunchto/bare-bundle/blob/v1.10.0/index.d.ts#L50)</sub>

An optional identifier for the bundle, or `null` if unset.

#### `imports: RecursiveStringObject`

<sub>[Source](https://github.com/holepunchto/bare-bundle/blob/v1.10.0/index.d.ts#L51)</sub>

The bundle's import map, mapping specifiers to file keys.

#### `keys(): string[]`

<sub>[Source](https://github.com/holepunchto/bare-bundle/blob/v1.10.0/index.d.ts#L56)</sub>

Return the keys of all files in the bundle.

#### `main: string | null`

<sub>[Source](https://github.com/holepunchto/bare-bundle/blob/v1.10.0/index.d.ts#L52)</sub>

The key of the bundle's entry file, or `null` if unset.

#### `mode(key: string): number`

<sub>[Source](https://github.com/holepunchto/bare-bundle/blob/v1.10.0/index.d.ts#L58)</sub>

Return the file mode (permission bits) of the file at `key`, or `0` if it doesn't exist.

**Parameters**

- `key` (`string`)

#### `mount(root: string | URL, opts?: BundleMountOptions): Bundle`

<sub>[Source](https://github.com/holepunchto/bare-bundle/blob/v1.10.0/index.d.ts#L61)</sub>

Return a copy of the bundle with all file keys and import/resolution specifiers rewritten as absolute URLs resolved against `root`.

**Parameters**

- `root` (`string` | `URL`)
- `opts` ([`BundleMountOptions`](#bundlemountoptions), optional)

#### `read(key: string): Buffer`

<sub>[Source](https://github.com/holepunchto/bare-bundle/blob/v1.10.0/index.d.ts#L59)</sub>

Return the contents of the file at `key` as a `Buffer`, or `null` if it doesn't exist.

**Parameters**

- `key` (`string`)

#### `resolutions: RecursiveStringObject`

<sub>[Source](https://github.com/holepunchto/bare-bundle/blob/v1.10.0/index.d.ts#L53)</sub>

The bundle's per-file import resolutions map, used to override the default import map for specific files.

#### `toBuffer(opts?: BundleToBufferOptions): Buffer`

<sub>[Source](https://github.com/holepunchto/bare-bundle/blob/v1.10.0/index.d.ts#L63)</sub>

Serialize the bundle to a single `Buffer` containing its header and file contents.

**Parameters**

- `opts` ([`BundleToBufferOptions`](#bundletobufferoptions), optional)

#### `unmount(root: string | URL, opts?: BundleMountOptions): Bundle`

<sub>[Source](https://github.com/holepunchto/bare-bundle/blob/v1.10.0/index.d.ts#L62)</sub>

Return a copy of the bundle with all file keys and import/resolution specifiers rewritten as paths relative to `root`, reversing `mount()`.

**Parameters**

- `root` (`string` | `URL`)
- `opts` ([`BundleMountOptions`](#bundlemountoptions), optional)

#### `version: number`

<sub>[Source](https://github.com/holepunchto/bare-bundle/blob/v1.10.0/index.d.ts#L46)</sub>

The bundle format version this implementation produces and expects.

#### `write(key: string, data: string, opts?: BundleWriteOptions): this`

<sub>[Source](https://github.com/holepunchto/bare-bundle/blob/v1.10.0/index.d.ts#L60)</sub>

Add or replace the file at `key` with `data`, optionally marking it as the main entry, an addon, an asset, or aliased in the import map.

**Parameters**

- `key` (`string`)
- `data` (`string`)
- `opts` ([`BundleWriteOptions`](#bundlewriteoptions), optional)

### MemoryFile

#### `new MemoryFile(data: string | Buffer, opts?: MemoryFileOptions)`

<sub>[Source](https://github.com/holepunchto/bare-bundle/blob/v1.10.0/index.d.ts#L16)</sub>

Create a `MemoryFile` from `data`, optionally marking it executable or setting an explicit `mode`.

**Parameters**

- `data` (`string` | `Buffer`)
- `opts` ([`MemoryFileOptions`](#memoryfileoptions), optional)

#### `mode(): number`

<sub>[Source](https://github.com/holepunchto/bare-bundle/blob/v1.10.0/index.d.ts#L10)</sub>

Return the file's mode (permission bits).

#### `read(): Buffer`

<sub>[Source](https://github.com/holepunchto/bare-bundle/blob/v1.10.0/index.d.ts#L11)</sub>

Return the file's contents as a `Buffer`.

#### `size(): number`

<sub>[Source](https://github.com/holepunchto/bare-bundle/blob/v1.10.0/index.d.ts#L12)</sub>

Return the file's byte length.
