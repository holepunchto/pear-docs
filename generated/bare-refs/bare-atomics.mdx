[`bare-atomics`](https://github.com/holepunchto/bare-atomics) — Native synchronization primitives for JavaScript. It is a native addon and requires Bare `>=1.2.0`.

```sh
npm i bare-atomics
```

## API

### Mutex

#### `new Mutex(opts?: MutexOptions)`

<sub>[Source](https://github.com/holepunchto/bare-atomics/blob/v3.0.7/index.d.ts#L6)</sub>

**Parameters**

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `opts?` | [`MutexOptions`](#mutexoptions) | — | Options; set `recursive: true` to let the owning thread lock the mutex more than once (default `false`). May also carry an existing `handle` to wrap. |

#### `Mutex.destroy(): void`

<sub>[Source](https://github.com/holepunchto/bare-atomics/blob/v3.0.7/index.d.ts#L17)</sub>

**Throws**

- The mutex is still held.

#### `Mutex.handle: SharedArrayBuffer`

<sub>[Source](https://github.com/holepunchto/bare-atomics/blob/v3.0.7/index.d.ts#L10)</sub>

A `SharedArrayBuffer` with the underlying mutex handle.

#### `held: boolean`

<sub>[Source](https://github.com/holepunchto/bare-atomics/blob/v3.0.7/index.d.ts#L12)</sub>

Whether or not the current thread currently holds the mutex.

#### `lock(): void`

<sub>[Source](https://github.com/holepunchto/bare-atomics/blob/v3.0.7/index.d.ts#L14)</sub>

**Throws**

- The mutex is already held and was not created with `recursive: true`.

#### `Mutex.from(handle: SharedArrayBuffer, opts?: MutexOptions): Mutex`

<sub>[Source](https://github.com/holepunchto/bare-atomics/blob/v3.0.7/index.d.ts#L8)</sub>

Create a `Mutex` from an existing `handle`; options are the same as `new Mutex()`.

**Parameters**

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `handle` | `SharedArrayBuffer` | — | A `SharedArrayBuffer` holding an existing mutex, as exposed by `Mutex.handle`. |
| `opts?` | [`MutexOptions`](#mutexoptions) | — | Options, the same as `new Mutex()`. |

**Returns** `Mutex` — A `Mutex` sharing the underlying `handle`.

#### `recursive: boolean`

<sub>[Source](https://github.com/holepunchto/bare-atomics/blob/v3.0.7/index.d.ts#L11)</sub>

#### `tryLock(): boolean`

<sub>[Source](https://github.com/holepunchto/bare-atomics/blob/v3.0.7/index.d.ts#L15)</sub>

**Throws**

- The mutex is already held and was not created with `recursive: true`.

#### `unlock(): void`

<sub>[Source](https://github.com/holepunchto/bare-atomics/blob/v3.0.7/index.d.ts#L16)</sub>

**Throws**

- The mutex is not currently held.
