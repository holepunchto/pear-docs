[`bare-querystring`](https://github.com/holepunchto/bare-querystring) — URL query strings utilities.

```sh
npm i bare-querystring
```

## Usage

```js
const querystring = require('bare-querystring')

querystring.decode('name=ferret') // `{ name: "ferret" }`

querystring.encode({ name: 'ferret' }) // `name=ferret`
```

## API

### Functions

#### `parse(input: string, separator?: string, delimiter?: string): Record<string, string | string[]>`

<sub>[Source](https://github.com/holepunchto/bare-querystring/blob/v1.1.0/index.d.ts#L1)</sub>

Parse a query string into an object, splitting pairs on `separator` (default `&`) and key/value on `delimiter` (default `=`). Repeated keys collect into an array.

**Parameters**

- `input` (`string`)
- `separator` (`string`, optional)
- `delimiter` (`string`, optional)

#### `decode(input: string, separator?: string, delimiter?: string): Record<string, string | string[]>`

<sub>[Source](https://github.com/holepunchto/bare-querystring/blob/v1.1.0/index.d.ts#L7)</sub>

Alias for `parse`.

**Parameters**

- `input` (`string`)
- `separator` (`string`, optional)
- `delimiter` (`string`, optional)

#### `stringify(params: {}, separator?: string, delimiter?: string): string`

<sub>[Source](https://github.com/holepunchto/bare-querystring/blob/v1.1.0/index.d.ts#L13)</sub>

Serialize an object into a query string, joining pairs with `separator` (default `&`) and key/value with `delimiter` (default `=`). Array values produce one pair per element.

**Parameters**

- `params` (`{}`)
- `separator` (`string`, optional)
- `delimiter` (`string`, optional)

<sub>[Source](https://github.com/holepunchto/bare-querystring/blob/v1.1.0/index.d.ts#L15)</sub>

Alias for `stringify`.

**Parameters**

- `params` (`{}`)
- `separator` (`string`, optional)
- `delimiter` (`string`, optional)
