[`bare-zlib`](https://github.com/holepunchto/bare-zlib) — Stream-based zlib bindings for JavaScript. It is a native addon.

Mirrors the Node.js [`zlib`](https://nodejs.org/api/zlib.html) module.

```sh
npm i bare-zlib
```

### Types

#### `ZlibOptions`

```ts
interface ZlibOptions<S extends ZlibStream = ZlibStream> extends Omit<
  TransformOptions<S>,
  'flush'
> {
  flush?: number
  finishFlush?: number
  chunkSize?: number
  level?: number
  windowBits?: number
  memLevel?: number
  strategy?: number
  maxOutputLength?: number
}
```
