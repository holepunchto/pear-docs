[`bare-dns`](https://github.com/holepunchto/bare-dns) — Domain name resolution for JavaScript. It is a native addon and requires Bare `>=1.7.0`.

Mirrors the Node.js [`dns`](https://nodejs.org/api/dns.html) module.

```sh
npm i bare-dns
```

## Usage

```js
const dns = require('bare-dns')

dns.lookup('github.com', (err, address, family) => {
  console.log(address, family)
})
```
