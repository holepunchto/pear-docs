[`bare-inspect`](https://github.com/holepunchto/bare-inspect) — Inspect objects as strings for debugging. It is a native addon and requires Bare `>=1.18.0`.

```sh
npm i bare-inspect
```

## Usage

```js
const inspect = require('bare-inspect')

console.log(inspect(globalThis))
```
