[`bare-path`](https://github.com/holepunchto/bare-path) — Path manipulation library for JavaScript.

Mirrors the Node.js [`path`](https://nodejs.org/api/path.html) module.

```sh
npm i bare-path
```

## Usage

```js
const path = require('bare-path')

path.join('foo', 'bar') // foo/bar on posix, foo\bar on windows
```
