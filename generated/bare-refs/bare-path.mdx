[`bare-path`](https://github.com/holepunchto/bare-path) — Path manipulation library for JavaScript. It is a native addon.

Mirrors the Node.js [`path`](https://nodejs.org/api/path.html) module.

```sh
npm i bare-path
```

## Usage

```js
const path = require('bare-path')

path.join('foo', 'bar') // foo/bar on posix, foo\bar on windows
```

### Platform variants and separators

#### `path.sep: '/' | '\\'`

<sub>[Source](https://github.com/holepunchto/bare-path/blob/v3.1.1/index.d.ts#L2)</sub>

The platform-specific path segment separator: `\` on Windows, `/` elsewhere.

#### `path.delimiter: ':' | ';'`

<sub>[Source](https://github.com/holepunchto/bare-path/blob/v3.1.1/index.d.ts#L3)</sub>

The platform-specific path delimiter: `;` on Windows, `:` elsewhere.

<sub>[Source](https://github.com/holepunchto/bare-path/blob/v3.1.1/index.d.ts#L23)</sub>
