[`bare-ipc`](https://github.com/holepunchto/bare-ipc) — Lightweight pipe-based IPC for Bare.

```sh
npm i bare-ipc
```

## Usage

```js
const IPC = require('bare-ipc')

const [portA, portB] = IPC.open()

const a = portA.connect()
const b = portB.connect()

a.on('data', (data) => {
  // Handle data received from b
}).end('hello b')

b.on('data', (data) => {
  // Handle data received from a
}).end('hello a')
```

## API

### IPC

#### `new IPC(port: IPCPort)`

<sub>[Source](https://github.com/holepunchto/bare-ipc/blob/v1.1.2/index.d.ts#L14)</sub>

Returns a duplex stream using the provided `port`. See `bare-stream`'s `Duplex` (\<https://github.com/holepunchto/bare-stream>) for the duplex stream API.

**Parameters**

- `port` (`IPCPort`)

#### `incoming: Pipe`

<sub>[Source](https://github.com/holepunchto/bare-ipc/blob/v1.1.2/index.d.ts#L6)</sub>

The underlying `bare-pipe` `Pipe` used for reading. Read-only.

#### `IPC.open(): [IPCPort, IPCPort]`

<sub>[Source](https://github.com/holepunchto/bare-ipc/blob/v1.1.2/index.d.ts#L34)</sub>

Returns a pair of connected `IPCPort`s for constructing the IPC duplex stream based on `bare-pipe`. Each port is transferable and can be sent to another thread or process before being connected.

#### `outgoing: Pipe`

<sub>[Source](https://github.com/holepunchto/bare-ipc/blob/v1.1.2/index.d.ts#L7)</sub>

The underlying `bare-pipe` `Pipe` used for writing. Read-only.

#### `ref(): this`

<sub>[Source](https://github.com/holepunchto/bare-ipc/blob/v1.1.2/index.d.ts#L9)</sub>

Increase the reference count for the IPC to keep the event loop alive.

#### `unref(): this`

<sub>[Source](https://github.com/holepunchto/bare-ipc/blob/v1.1.2/index.d.ts#L10)</sub>

Decrease the reference count for the IPC to allow the event loop to exit.

### IPCPort

#### `new IPCPort(incoming: number, outgoing: number)`

<sub>[Source](https://github.com/holepunchto/bare-ipc/blob/v1.1.2/index.d.ts#L26)</sub>

Constructs a port from a pair of file handles, `incoming` and `outgoing`.

**Parameters**

- `incoming` (`number`)
- `outgoing` (`number`)

#### `connect(): IPC`

<sub>[Source](https://github.com/holepunchto/bare-ipc/blob/v1.1.2/index.d.ts#L22)</sub>

Returns an `IPC` connected to the `port` and marks the `port` as detached.

#### `detached: boolean`

<sub>[Source](https://github.com/holepunchto/bare-ipc/blob/v1.1.2/index.d.ts#L20)</sub>

A boolean for whether the `port` is detached. A port becomes detached once it is connected or transferred, and a detached port cannot be transferred again.

#### `incoming: number`

<sub>[Source](https://github.com/holepunchto/bare-ipc/blob/v1.1.2/index.d.ts#L18)</sub>

The file handle used for reading. Read-only.

#### `outgoing: number`

<sub>[Source](https://github.com/holepunchto/bare-ipc/blob/v1.1.2/index.d.ts#L19)</sub>

The file handle used for writing. Read-only.
