[`bare-encoding`](https://github.com/holepunchto/bare-encoding) — WHATWG text encoding interfaces for JavaScript.

```sh
npm i bare-encoding
```

## Usage

```js
const { TextEncoder, TextDecoder } = require('bare-encoding')
```
