[`bare-logger`](https://github.com/holepunchto/bare-logger) — Low-level logger for Bare. It is a native addon.

```sh
npm i bare-logger
```

## Usage

```js
const Log = require('bare-logger')

const log = new Log()

log.info('Hello %s', 'world!')
```

#### `clear(): void`

<sub>[Source](https://github.com/holepunchto/bare-logger/blob/v2.0.3/index.d.ts#L16)</sub>

<sub>[Source](https://github.com/holepunchto/bare-logger/blob/v2.0.3/index.d.ts#L6)</sub>
