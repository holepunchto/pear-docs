[`bare-system-logger`](https://github.com/holepunchto/bare-system-logger) — System logger for Bare. It is a native addon.

```sh
npm i bare-system-logger
```

## Usage

```js
const SystemLog = require('bare-system-logger')

const log = new SystemLog()

log.info('Hello %s', 'world!')
```

## API

### SystemLog

#### `clear(): void`

Clears the log output. A no-op on the base `Log`.

#### `colors: boolean`

Whether this logger applies ANSI color styling to formatted output. Read-only. Always `false` for a `SystemLog`.

#### `debug(...data: unknown[]): void`

Logs `data` at debug level.

**Parameters**

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `data` | `unknown[]` | — | Values to format and log; the first may be a `printf`-style format string (for example `%s`, `%d`, `%o`) with the remaining values as substitutions. |
