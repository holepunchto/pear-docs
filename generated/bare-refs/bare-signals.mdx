[`bare-signals`](https://github.com/holepunchto/bare-signals) — Native signal handling for JavaScript. It is a native addon and requires Bare `>=1.7.0`.

```sh
npm i bare-signals
```

## Usage

```js
const Signal = require('bare-signals')

const sigint = new Signal('SIGINT')

sigint.on('signal', () => console.log('SIGINT caught')).start()
```

## API

### Signal

#### `new Signal(signum: number | string)`

<sub>[Source](https://github.com/holepunchto/bare-signals/blob/v5.0.0/index.d.ts#L23)</sub>

Create a `Signal` for `signum`, given as a signal number or name such as `'SIGINT'`. Throws if `signum` is a string that names an unknown signal.

**Parameters**

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `signum` | `number` \| `string` | — | — |

#### `close(): Promise<void>`

<sub>[Source](https://github.com/holepunchto/bare-signals/blob/v5.0.0/index.d.ts#L19)</sub>

Close the signal, releasing its underlying handle. Returns a promise that resolves once the `close` event has fired.

#### `Signal.ref(): this`

<sub>[Source](https://github.com/holepunchto/bare-signals/blob/v5.0.0/index.d.ts#L17)</sub>

Ref the signal, keeping the event loop alive while it is active.

#### `Signal.constants: Record<string, number>`

<sub>[Source](https://github.com/holepunchto/bare-signals/blob/v5.0.0/index.d.ts#L29)</sub>

The map of known signal names to signal numbers, taken from `bare-os`.

#### `start(): this`

<sub>[Source](https://github.com/holepunchto/bare-signals/blob/v5.0.0/index.d.ts#L15)</sub>

Start listening for the signal, emitting `signal` when it is received. Throws if the signal has been closed.

#### `stop(): this`

<sub>[Source](https://github.com/holepunchto/bare-signals/blob/v5.0.0/index.d.ts#L16)</sub>

Stop listening for the signal.

#### `Signal.unref(): this`

<sub>[Source](https://github.com/holepunchto/bare-signals/blob/v5.0.0/index.d.ts#L18)</sub>

Unref the signal, allowing the event loop to exit even while it is active.

### SignalEmitter

#### `SignalEmitter.ref(): this`

<sub>[Source](https://github.com/holepunchto/bare-signals/blob/v5.0.0/index.d.ts#L4)</sub>

Ref all currently tracked signals, keeping the event loop alive.

#### `SignalEmitter.unref(): this`

<sub>[Source](https://github.com/holepunchto/bare-signals/blob/v5.0.0/index.d.ts#L5)</sub>

Unref all currently tracked signals, allowing the event loop to exit.
