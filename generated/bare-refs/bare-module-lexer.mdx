[`bare-module-lexer`](https://github.com/holepunchto/bare-module-lexer) — Heuristic lexer for detecting imports and exports in JavaScript modules. It is a native addon.

```sh
npm i bare-module-lexer
```

## Usage

```js
const lex = require('bare-module-lexer')

lex(`
  const foo = require('./foo.js')
  exports.bar = 42
`)

// {
//   imports: [
//     { specifier: './foo.js', type: REQUIRE, names: [], position: [ 15, 24, 32 ] }
//   ],
//   exports: [
//     { name: 'bar', position: [ 37, 45, 48 ] }
//   ]
// }
```

## API

### Functions

#### `lex`

```ts
lex(input: string | Buffer, encoding?: BufferEncoding, opts?: object): {
  imports: Import[]
  exports: Export[]
}
```

<sub>[Source](https://github.com/holepunchto/bare-module-lexer/blob/v1.6.2/index.d.ts#L16)</sub>

Lex `input` for import and export statements, returning the detected `imports` and `exports`.

**Parameters**

- `input` (`string` | `Buffer`)
- `encoding` (`BufferEncoding`, optional)
- `opts` (`object`, optional)
