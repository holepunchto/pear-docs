[`bare-posix`](https://github.com/holepunchto/bare-posix) — POSIX-specific bindings for Bare. It is a native addon.

```sh
npm i bare-posix
```

## API

### Functions

#### `getgid(): number`

<sub>[Source](https://github.com/holepunchto/bare-posix/blob/v1.0.1/index.d.ts#L1)</sub>

#### `setgid(id: number | string): void`

<sub>[Source](https://github.com/holepunchto/bare-posix/blob/v1.0.1/index.d.ts#L3)</sub>

Set the real group ID of the calling process. Accepts a numeric ID or a group name, resolved via `getgrnam`.

**Parameters**

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `id` | `number` \| `string` | — | The group to switch to: a numeric group ID, or a group name resolved via `getgrnam`. |

**Throws**

- On platforms without POSIX support (android, win32), throws `Error: Platform not supported`.

#### `getgrnam(name: string): Group | null`

<sub>[Source](https://github.com/holepunchto/bare-posix/blob/v1.0.1/index.d.ts#L26)</sub>
