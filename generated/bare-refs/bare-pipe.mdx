[`bare-pipe`](https://github.com/holepunchto/bare-pipe) — Native I/O pipes for JavaScript. It is a native addon and requires Bare `>=1.16.0`.

```sh
npm i bare-pipe
```

## Usage

```js
const Pipe = require('bare-pipe')

const stdout = new Pipe(1)

stdout.write('Hello world!\n')
```

## API

### Pipe

#### `new Pipe(path: string | number, opts?: PipeOptions)`

<sub>[Source](https://github.com/holepunchto/bare-pipe/blob/v4.2.2/index.d.ts#L61)</sub>

Create a new pipe. If `path` is a number, it is treated as a file descriptor to open. If it is a string, it is treated as a path to connect to.

Overloads:

```ts
new Pipe(path: string | number, opts?: PipeOptions)
new Pipe(opts?: PipeOptions)
```

**Parameters**

- `path` (`string` | `number`)
- `opts` ([`PipeOptions`](#pipeoptions), optional)

#### `accept<T extends IPCAcceptable>(target: T): T`

<sub>[Source](https://github.com/holepunchto/bare-pipe/blob/v4.2.2/index.d.ts#L54)</sub>

Accept a pending handle into `target`. `target` must implement the [`IPCAcceptable`](#ipc-handle-passing) protocol. Call this synchronously from the `'handle'` event listener. Throws `INVALID_IPC_TARGET` if `target` does not implement the protocol.

**Parameters**

- `target` (`T`)

#### `connect(path: string, opts?: PipeConnectOptions, onconnect?: () => void): this`

<sub>[Source](https://github.com/holepunchto/bare-pipe/blob/v4.2.2/index.d.ts#L40)</sub>

Connect the pipe to `path`. `onconnect` is called when the connection is established.

Overloads:

```ts
connect(path: string, opts?: PipeConnectOptions, onconnect?: () => void): this
connect(path: string, onconnect: () => void): this
connect(opts: PipeConnectOptions, onconnect?: () => void): this
```

**Parameters**

- `path` (`string`)
- `opts` ([`PipeConnectOptions`](#pipeconnectoptions), optional)
- `onconnect` (`() => void`, optional)

#### `connecting: boolean`

<sub>[Source](https://github.com/holepunchto/bare-pipe/blob/v4.2.2/index.d.ts#L32)</sub>

Whether the pipe is currently connecting.

#### `open(fd: number, opts?: { fd?: number }, onconnect?: () => void): this`

<sub>[Source](https://github.com/holepunchto/bare-pipe/blob/v4.2.2/index.d.ts#L36)</sub>

Open the pipe on the given file descriptor.

Overloads:

```ts
open(fd: number, opts?: { fd?: number }, onconnect?: () => void): this
open(fd: number, onconnect: () => void): this
open(opts: { fd: number }, onconnect?: () => void): this
```

**Parameters**

- `fd` (`number`)
- `opts` (`{ fd?: number }`, optional)
- `onconnect` (`() => void`, optional)

#### `pending: boolean`

<sub>[Source](https://github.com/holepunchto/bare-pipe/blob/v4.2.2/index.d.ts#L33)</sub>

Whether the pipe has not yet connected.

#### `Pipe.pipe(): [read: number, write: number]`

<sub>[Source](https://github.com/holepunchto/bare-pipe/blob/v4.2.2/index.d.ts#L125)</sub>

#### `readyState: 'open' | 'readOnly' | 'writeOnly' | 'opening'`

<sub>[Source](https://github.com/holepunchto/bare-pipe/blob/v4.2.2/index.d.ts#L34)</sub>

<sub>[Source](https://github.com/holepunchto/bare-pipe/blob/v4.2.2/index.d.ts#L56)</sub>

#### `Pipe.unref(): this`

<sub>[Source](https://github.com/holepunchto/bare-pipe/blob/v4.2.2/index.d.ts#L57)</sub>

Unref the pipe, allowing the process to exit.

#### `write`

```ts
write(chunk: Buffer | string, encoding: BufferEncoding, handle?: IPCAcceptable, cb?: (err: Error | null) => void): boolean
```

<sub>[Source](https://github.com/holepunchto/bare-pipe/blob/v4.2.2/index.d.ts#L44)</sub>

Write `chunk` to the pipe. If `handle` is given and the pipe was created with `ipc: true`, the handle is transferred to the receiver alongside the chunk. `handle` must implement the [`IPCAcceptable`](#ipc-handle-passing) protocol.

**Parameters**

- `chunk` (`Buffer` | `string`)
- `encoding` (`BufferEncoding`)
- `handle` ([`IPCAcceptable`](#ipcacceptable), optional)
- `cb` (`(err: Error | null) => void`, optional)

<sub>[Source](https://github.com/holepunchto/bare-pipe/blob/v4.2.2/index.d.ts#L99)</sub>
