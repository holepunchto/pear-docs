[`bare-stdio`](https://github.com/holepunchto/bare-stdio) — Standard input/output streams for Bare. It is a native addon.

```sh
npm i bare-stdio
```

## Usage

```js
const stdio = require('bare-stdio')

// Write to stdout
stdio.out.write('Hello, World!\n')

// Write to stderr
stdio.err.write('An error occurred\n')

// Read from stdin
stdio.in.on('data', (data) => {
  console.log('Received:', data.toString())
})
```
