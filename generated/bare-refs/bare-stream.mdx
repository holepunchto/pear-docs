[`bare-stream`](https://github.com/holepunchto/bare-stream) — Streaming data for JavaScript.

Mirrors the Node.js [`stream`](https://nodejs.org/api/stream.html) module.

```sh
npm i bare-stream
```

## Usage

```js
const { Readable } = require('bare-stream')

const stream = new Readable({
  read(size) {
    // Push data, then push `null` to signal the end
    this.push('hello')
    this.push('world')
    this.push(null)
  }
})

stream.on('data', (data) => console.log(data))
```
