[`bare-subprocess`](https://github.com/holepunchto/bare-subprocess) — Native process spawning for JavaScript. It is a native addon and requires Bare `>=1.7.0`.

```sh
npm i bare-subprocess
```

## Usage

```js
const { spawn } = require('bare-subprocess')

const subprocess = spawn('echo', ['hello', 'world'], {
  stdio: 'inherit'
})

subprocess.on('exit', () => console.log('done'))
```

## API

### Subprocess

#### `channel: SubprocessChannel`

<sub>[Source](https://github.com/holepunchto/bare-subprocess/blob/v6.1.0/index.d.ts#L30)</sub>

The `SubprocessChannel` instance backing the IPC channel, or `undefined` when no channel exists. For `serialization: 'binary'`, this is always `undefined`.

#### `Subprocess.connected: boolean`

<sub>[Source](https://github.com/holepunchto/bare-subprocess/blob/v6.1.0/index.d.ts#L31)</sub>

`true` while an IPC channel exists between parent and child.

#### `Subprocess.disconnect(): void`

<sub>[Source](https://github.com/holepunchto/bare-subprocess/blob/v6.1.0/index.d.ts#L41)</sub>

Close the IPC channel. A `'disconnect'` event is emitted once the channel is fully closed.

#### `exitCode: number | null`

<sub>[Source](https://github.com/holepunchto/bare-subprocess/blob/v6.1.0/index.d.ts#L20)</sub>

The exit code of the child, or `null` if the child has not exited or was terminated by a signal.

#### `kill(signum?: number): void`

<sub>[Source](https://github.com/holepunchto/bare-subprocess/blob/v6.1.0/index.d.ts#L36)</sub>

Send a signal to the child. `signum` may be a signal number or a name (e.g. `'SIGTERM'`). Defaults to `SIGTERM`.

**Parameters**

- `signum` (`number`, optional)

#### `killed: boolean`

<sub>[Source](https://github.com/holepunchto/bare-subprocess/blob/v6.1.0/index.d.ts#L21)</sub>

`true` if `subprocess.kill()` has been called, otherwise `false`.

#### `pid: number`

<sub>[Source](https://github.com/holepunchto/bare-subprocess/blob/v6.1.0/index.d.ts#L22)</sub>

The process ID of the child.

#### `ref(): void`

<sub>[Source](https://github.com/holepunchto/bare-subprocess/blob/v6.1.0/index.d.ts#L33)</sub>

Same semantics as the corresponding `Subprocess` method.

#### `Subprocess.send(message: unknown, handle?: unknown, cb?: (err: Error | null) => void): boolean`

<sub>[Source](https://github.com/holepunchto/bare-subprocess/blob/v6.1.0/index.d.ts#L38)</sub>

Send `message` to the child over the IPC channel. `handle` may be a `bare-pipe` `Pipe` or a `bare-tcp` `Socket` to transfer ownership of along with the message. `callback` is invoked with `(err)` after the message has been written.

Overloads:

```ts
send(message: unknown, handle?: unknown, cb?: (err: Error | null) => void): boolean
send(message: unknown, cb: (err: Error | null) => void): boolean
```

**Parameters**

- `message` (`unknown`)
- `handle` (`unknown`, optional)
- `cb` (`(err: Error | null) => void`, optional)

#### `signalCode: string | null`

<sub>[Source](https://github.com/holepunchto/bare-subprocess/blob/v6.1.0/index.d.ts#L23)</sub>

The name of the signal the child was terminated with, or `null`.

#### `spawnargs: string[]`

<sub>[Source](https://github.com/holepunchto/bare-subprocess/blob/v6.1.0/index.d.ts#L24)</sub>

The arguments the child was spawned with.

#### `spawnfile: string`

<sub>[Source](https://github.com/holepunchto/bare-subprocess/blob/v6.1.0/index.d.ts#L25)</sub>

The file that was spawned.

#### `stderr: Pipe | null`

<sub>[Source](https://github.com/holepunchto/bare-subprocess/blob/v6.1.0/index.d.ts#L29)</sub>

Convenience accessor for `subprocess.stdio[2]`.

#### `stdin: Pipe | null`

<sub>[Source](https://github.com/holepunchto/bare-subprocess/blob/v6.1.0/index.d.ts#L27)</sub>

Convenience accessor for `subprocess.stdio[0]`.

#### `stdio: (Pipe | null)[]`

<sub>[Source](https://github.com/holepunchto/bare-subprocess/blob/v6.1.0/index.d.ts#L26)</sub>

An array of `bare-pipe` instances corresponding to the configured stdio slots. Slots configured as `'inherit'`, `'ignore'`, or backed by an inherited fd are `null`.

#### `stdout: Pipe | null`

<sub>[Source](https://github.com/holepunchto/bare-subprocess/blob/v6.1.0/index.d.ts#L28)</sub>

Convenience accessor for `subprocess.stdio[1]`.

#### `unref(): void`

<sub>[Source](https://github.com/holepunchto/bare-subprocess/blob/v6.1.0/index.d.ts#L34)</sub>

Reference or unreference the subprocess and its stdio pipes against the event loop.

### Functions

#### `spawn(file: string, args?: string[] | null, opts?: SpawnOptions): Subprocess`

<sub>[Source](https://github.com/holepunchto/bare-subprocess/blob/v6.1.0/index.d.ts#L61)</sub>

Spawn `file` as a new subprocess with the given `args`. Returns a `Subprocess` instance. `args` may be `null` or omitted to spawn with no arguments. If `args` is omitted, the second argument is treated as `options`.

Overloads:

```ts
spawn(file: string, args?: string[] | null, opts?: SpawnOptions): Subprocess
spawn(file: string, opts?: SpawnOptions): Subprocess
```

Synchronous form: `spawnSync(file: string, args?: string[] | null, opts?: SpawnSyncOptions): SpawnSyncResult`

**Parameters**

- `file` (`string`)
- `args` (`string[]` | `null`, optional)
- `opts` ([`SpawnOptions`](#spawnoptions), optional)
