[`bare-wasm`](https://github.com/holepunchto/bare-wasm) — WebAssembly JavaScript API for Bare. In 0.1.0, each export is the same-named member of the `WebAssembly` global, so the module needs an engine that provides WebAssembly.

```sh
npm i bare-wasm
```

## Usage

```js
const { Module, Instance } = require('bare-wasm')

const module = new Module(bytes)
const instance = new Instance(module, imports)
```

## API

### wasm

#### `wasm.BufferSource`

```ts
type BufferSource = ArrayBuffer | ArrayBufferView
```

The bytes of a WebAssembly module in its binary format.

#### `wasm.compile(bytes: BufferSource): Promise<Module>`

Asynchronously compile a module.

**Parameters**

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `bytes` | `BufferSource` | — | The binary format of the module. |

#### `wasm.Exports`

```ts
type Exports = Record<string, ExportValue>
```

The exports of an instance, keyed by name.

#### `wasm.ExportValue`

```ts
type ExportValue = Function | Global | Memory | Table | Tag
```

A value exported by an instance.

#### `wasm.ImportExportKind`

```ts
type ImportExportKind = 'function' | 'table' | 'memory' | 'global' | 'tag'
```

The kind of an import or export of a module.

#### `wasm.Imports`

```ts
type Imports = Record<string, ModuleImports>
```

The imports of a module, keyed by import module name.

#### `wasm.ImportValue`

```ts
type ImportValue = ExportValue | number | bigint
```

A value that may be provided to satisfy an import.

#### `wasm.instantiate(bytes: BufferSource, imports?: Imports): Promise<InstantiatedSource>`

Asynchronously compile and instantiate a module.

Overloads:

```ts
wasm.instantiate(bytes: BufferSource, imports?: Imports): Promise<InstantiatedSource>
wasm.instantiate(module: Module, imports?: Imports): Promise<Instance>
```

**Parameters**

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `bytes` | `BufferSource` | — | The binary format of the module. |
| `imports?` | `Imports` | — | The values to satisfy the imports of the module with. |

#### `wasm.ModuleImports`

```ts
type ModuleImports = Record<string, ImportValue>
```

The imports of a single import module, keyed by name.

#### `wasm.TableKind`

```ts
type TableKind = 'externref' | 'anyfunc'
```

The type of the elements of a table.

#### `wasm.validate(bytes: BufferSource): boolean`

Check whether `bytes` is a valid module.

**Parameters**

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `bytes` | `BufferSource` | — | — |

#### `wasm.ValueType`

```ts
type ValueType = 'i32' | 'i64' | 'f32' | 'f64' | 'v128' | 'externref' | 'anyfunc'
```

The type of a WebAssembly value.

### Memory

#### `new Memory(descriptor: MemoryDescriptor)`

Create a memory of `descriptor.initial` pages.

**Parameters**

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `descriptor` | [`MemoryDescriptor`](#memorydescriptor) | — | — |

#### `buffer: ArrayBuffer | SharedArrayBuffer`

The buffer backing the memory, which is detached and replaced whenever it grows.

#### `grow(delta: number): number`

Grow the memory.

**Parameters**

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `delta` | `number` | — | The number of pages of 64 KiB to grow the memory by. |

**Returns** `number` — The previous size of the memory in pages.

**Throws**

- `RangeError` — thrown if the memory cannot grow by `delta` pages.

### Types

#### `ModuleExportDescriptor`

```ts
interface ModuleExportDescriptor {
  name: string
  kind: ImportExportKind
}
```

An export of a module, as listed by `Module.exports()`.

#### `ModuleImportDescriptor`

```ts
interface ModuleImportDescriptor {
  module: string
  name: string
  kind: ImportExportKind
}
```

An import of a module, as listed by `Module.imports()`.

#### `MemoryDescriptor`

```ts
interface MemoryDescriptor {
  initial: number
  maximum?: number
  shared?: boolean
}
```

The size, in 64 KiB pages, and sharing of a memory.

#### `TableDescriptor`

```ts
interface TableDescriptor {
  element: TableKind
  initial: number
  maximum?: number
}
```

The element type and size of a table.

#### `GlobalDescriptor`

```ts
interface GlobalDescriptor {
  value: ValueType
  mutable?: boolean
}
```

The value type and mutability of a global.

#### `TagType`

```ts
interface TagType {
  parameters: ValueType[]
}
```

The parameter types of an exception tag.

#### `ExceptionOptions`

```ts
interface ExceptionOptions {
  traceStack?: boolean
}
```

Options for an `Exception`.

#### `InstantiatedSource`

```ts
interface InstantiatedSource {
  module: Module
  instance: Instance
}
```

The result of instantiating the bytes of a module: the compiled `module` and its `instance`.
