[`bare-tty`](https://github.com/holepunchto/bare-tty) — Native TTY streams for JavaScript. It is a native addon and requires Bare `>=1.16.0`.

Mirrors the Node.js [`tty`](https://nodejs.org/api/tty.html) module.

```sh
npm i bare-tty
```

## Usage

```js
const tty = require('bare-tty')

const stdout = new tty.WriteStream(1)

stdout.write('Hello world!\n')
```

Enable or disable raw mode. In raw mode, input is delivered byte-by-byte without line buffering

```ts
  mode: { NORMAL: number; RAW: number; IO: number }
```

