[`bare-fetch`](https://github.com/holepunchto/bare-fetch) — WHATWG Fetch implementation for Bare.

```sh
npm i bare-fetch
```

## Usage

```js
const fetch = require('bare-fetch')

const res = await fetch('https://example.com/data')

console.log(await res.json())
```
