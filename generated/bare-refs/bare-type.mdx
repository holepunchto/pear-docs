[`bare-type`](https://github.com/holepunchto/bare-type) — Cross-realm type predicates for Bare. It is a native addon and requires Bare `>=1.37.0`. Before v1.5.0, it required Bare `>=1.32.0`.

```sh
npm i bare-type
```

## Usage

```js
const type = require('bare-type')

if (type(123).isNumber()) {
  console.log(123, 'is a number')
}
```

### Functions

#### `type(value: unknown): Type`

Return a `Type` wrapping `value`, exposing `is*()` predicates to test its runtime type across realms.

**Parameters**

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `unknown` | — | The value to wrap and test. |

#### `type.of(value: unknown): number`

Return the runtime type of `value` as a number, for callers that would otherwise walk a long chain of predicates and can switch on it instead. Every constant carries its base type, so `constants.ARRAY` matches an array outright.

**Parameters**

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `unknown` | — | The value to test. |

### Constants and variables

#### `type.constants: Constants`

The type constants that `of()` returns. Changed in v1.5.0: for an `ArrayBuffer` that can't be detached, such as the buffer of a `WebAssembly.Memory`, `of()` returns `NON_DETACHABLE_ARRAYBUFFER` where it returned `ARRAYBUFFER`, so a `switch` with a case for `ARRAYBUFFER` alone no longer matches it. `isArrayBuffer()` is still `true` for both. Added in v1.6.0: `MAP_ITERATOR` and `SET_ITERATOR`.

## Threat model

`bare-type` is one of the addons Bare compiles into its binary, so every Bare process has it, sealed or not, and it inherits [Bare's threat model](https://github.com/holepunchto/bare/blob/main/docs/threat-model.md). The module's own [threat model](https://github.com/holepunchto/bare-type/blob/main/docs/threat-model.md), added in v1.2.0, says where it sits in that one. It only reports what a value is, across realms, and reaches and keeps nothing, so it has the smallest surface of the builtins. The risk is in the C that walks values an attacker built, proxies and revoked proxies included. Seeing across realms is not a hole, because a realm is not a wall in Bare.
