[`bare-buffer`](https://github.com/holepunchto/bare-buffer) — Native buffers for JavaScript. It is a native addon and requires Bare `>=1.20.0`.

Mirrors the Node.js [`buffer`](https://nodejs.org/api/buffer.html) module.

```sh
npm i bare-buffer
```

## Usage

```js
const Buffer = require('bare-buffer')

const message = Buffer.from('hello')
const empty = Buffer.alloc(16)
const buffer = Buffer.allocUnsafe(4).fill(123)
const combined = Buffer.concat([buffer, buffer])
```
