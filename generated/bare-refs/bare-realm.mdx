[`bare-realm`](https://github.com/holepunchto/bare-realm) — Realm support for Bare. It is a native addon and requires Bare `>=1.5.0`.

```sh
npm i bare-realm
```

## Usage

```js
const Realm = require('bare-realm')

const realm = new Realm()

realm.evaluate('globalThis.foo = 42')
// 42

typeof globalThis.foo
// undefined
```
