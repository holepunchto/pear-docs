[`bare-system-logger`](https://github.com/holepunchto/bare-system-logger) — System logger for Bare. It is a native addon.

```sh
npm i bare-system-logger
```

## Usage

```js
const SystemLog = require('bare-system-logger')

const log = new SystemLog()

log.info('Hello %s', 'world!')
```
