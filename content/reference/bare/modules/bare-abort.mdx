[`bare-abort`](https://github.com/holepunchto/bare-abort) — Cause abnormal program termination and generate a crash report. It is a native addon.

```sh
npm i bare-abort
```

## Usage

```js
const abort = require('bare-abort')

abort()
```

## API

### Functions

#### `abort(): never`

Cause abnormal program termination and generate a crash report.
