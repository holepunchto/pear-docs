[`bare-union-bundle`](https://github.com/holepunchto/bare-union-bundle) layers multiple [`bare-bundle`](/reference/modules/bare-modules) files into one **union bundle**, so modules resolve across a stack of bundles (for example, an app layer over a shared base). It's pure JavaScript, built on [`bare-module-traverse`](/reference/bare/modules/bare-module-traverse).

```sh
npm i bare-union-bundle
```

## Usage

```js
const UnionBundle = require('bare-union-bundle')

const b = UnionBundle.require('./0.bundle', './1.bundle', './2.bundle')

// load entrypoint.js from layer 1, unioning back to the project root
const mod = b.load(new URL('file:///root-of-project'), 'entrypoint.js', 1)
```

## API

#### `const b = new UnionBundle(bundles)` · `UnionBundle.require(...files)`

Create a union from in-memory `bundles`, or load and union bundle files.

#### `const layer = await b.add(root, entrypoint[, opts])`

Create a new layer bundle for `entrypoint` relative to `root`. Options:

```js
opts = {
  skipModules: true  // skip bundling dependencies under node_modules in root (boolean; default true)
}
```

Modules already referenced in the union's existing bundles are automatically skipped.

#### `const bundle = b.checkout(index)`

Extract a single layer as a standalone bundle.

#### `const mod = b.load(root, entrypoint, index[, opts])`

Load a module from layer `index`, resolving across the union back to `root`. Options:

```js
opts = {
  cache: require.cache,  // the module cache to load the entrypoint with (default require.cache)
  skipModules: true      // skip loading node_modules deps already in the cache (boolean; default true)
}
```
