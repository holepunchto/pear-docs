[`bare-make`](https://github.com/holepunchto/bare-make) is an opinionated build-system generator for [Bare](/reference/bare/runtime) native addons. It drives CMake with Ninja and Clang for a consistent toolchain across platforms, while staying plain CMake underneath so you can eject. It ships both a JavaScript API and a CLI.

```sh
npm i -g bare-make
```

## Usage

Builds happen in three steps—generate, build, install:

```js
const make = require('bare-make')

await make.generate()
await make.build()
await make.install()
```

Or from the command line:

```console
bare-make generate
bare-make build
bare-make install
```

## API

#### `await generate([options])`

Generate the build system (the configure step).

#### `await build([options])`

Compile the generated build system.

#### `await install([options])`

Install the built artefacts.

#### `await test([options])`

Run tests for projects using CMake's `enable_testing()` / `add_test()`. Also available as `bare-make test`.
