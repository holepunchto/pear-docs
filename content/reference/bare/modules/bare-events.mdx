[`bare-events`](https://github.com/holepunchto/bare-events) — Event emitters for JavaScript.

Mirrors the Node.js [`events`](https://nodejs.org/api/events.html) module.

```sh
npm i bare-events
```

## Usage

```js
const EventEmitter = require('bare-events')

const e = new EventEmitter()

e.on('hello', function (data) {
  console.log(data)
})

e.emit('hello', 'world')
```

### Emitting

#### `emit<E extends keyof M>(name: E, ...args: M[E]): boolean`

<sub>[Source](https://github.com/holepunchto/bare-events/blob/v2.9.1/index.d.ts#L35)</sub>

Synchronously call each listener registered for `name`, in registration order, with `args`. Returns `true` if there were listeners, `false` otherwise. Emitting `'error'` with no `'error'` listeners throws the error asynchronously instead of calling any listener.

**Parameters**

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `name` | `E` | — | The event name to emit. |
| `args` | `M[E]` | — | Arguments passed to each listener registered for `name`. |

#### `EventEmitter.forward`

```ts
EventEmitter.forward<F extends EventMap, E extends keyof F, T extends Pick<F, E>>(from: EventEmitter<F>, to: EventEmitter<T>, names: E | E[], opts?: { emit?: (name: E, ...args: T[E]) => void }): void
```

<sub>[Source](https://github.com/holepunchto/bare-events/blob/v2.9.1/index.d.ts#L64)</sub>

Forward events named in `names` from `from` to `to`, re-emitting them on `to` only while `to` has at least one listener for that event.

**Parameters**

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `from` | `EventEmitter<F>` | — | The emitter to forward events from. |
| `to` | `EventEmitter<T>` | — | The emitter to forward events to. |
| `names` | `E` \| `E[]` | — | The event name, or array of event names, to forward. |
| `opts?` | `{ emit?: (name: E, ...args: T[E]) => void }` | — | Options; `emit` overrides how forwarded events are re-emitted on `to` (defaults to `to.emit`). |
