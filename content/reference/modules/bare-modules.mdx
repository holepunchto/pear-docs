# Bare modules

Pear's native runtime is [Bare](https://github.com/holepunchto/bare)—a small, modular JavaScript runtime for desktop and mobile. The `Bare` global API is minimal and not intended as a standard library; standard runtime functionality is provided via installable modules prefixed with `bare-`.

If you author native addons for Bare, the [Bare native-addon prebuild actions](/reference/ci-and-release/github-actions#bare-native-addon-prebuilds) build and collect prebuilt binaries across platforms in CI.
