`Secretstream` wraps a transport stream in a Noise handshake plus libsodium `secretstream` encryption. It is the encrypted stream layer used underneath [Hyperswarm](/reference/building-blocks/hyperswarm) and related peer transports. For the upstream package, source, and release notes, see the [@hyperswarm/secret-stream repository](https://github.com/holepunchto/hyperswarm-secret-stream).

## Install

```sh
npm i @hyperswarm/secret-stream
```

## Quickstart

```js
import SecretStream from '@hyperswarm/secret-stream'

const a = new SecretStream(true)
const b = new SecretStream(false)

a.rawStream.pipe(b.rawStream).pipe(a.rawStream)

a.write(Buffer.from('hello encrypted world'))

b.on('data', (data) => {
  console.log(data.toString())
})
```

## API Reference

### Constructor and lifecycle

#### `const stream = new SecretStream(isInitiator, [rawStream], [options])`

[API definition on GitHub](https://github.com/holepunchto/hyperswarm-secret-stream/blob/main/index.js#L15)
- Signature: `const stream = new SecretStream(isInitiator, [rawStream], [options])` ([GitHub](https://github.com/holepunchto/hyperswarm-secret-stream/blob/main/index.js#L15))
- Parameters: `isInitiator` is `true` for the dialing side and `false` for the accepting side. `rawStream` is an optional underlying transport stream. `options.pattern` overrides the Noise pattern, `remotePublicKey` pins the remote identity when the pattern requires it, `keyPair` provides a local key pair or a promise resolving to one, `handshake` injects an already-computed handshake, `enableSend` disables unordered UDP-style sends when set to `false`, `keepAlive` configures heartbeat writes, and `autoStart` defaults to `true`. ([GitHub](https://github.com/holepunchto/hyperswarm-secret-stream/blob/main/index.js#L15))
- Returns: A duplex encrypted stream. You can use it like a normal stream for ordered reads and writes once the handshake completes. ([GitHub](https://github.com/holepunchto/hyperswarm-secret-stream/blob/main/index.js#L199))
- Example:

```js
const socket = getTransportSocketSomehow()
const stream = new SecretStream(true, socket, {
  keepAlive: 10_000
})
```

#### `stream.start([rawStream], [options])`

[API definition on GitHub](https://github.com/holepunchto/hyperswarm-secret-stream/blob/main/index.js#L123)
- Signature: `stream.start([rawStream], [options])` ([GitHub](https://github.com/holepunchto/hyperswarm-secret-stream/blob/main/index.js#L123))
- Parameters: `rawStream` is the transport to wrap when `autoStart: false` was used. `options` accepts the same handshake-related fields as the constructor, including `keyPair`, `handshake`, `data`, and `ended`. ([GitHub](https://github.com/holepunchto/hyperswarm-secret-stream/blob/main/index.js#L123))
- Returns: Nothing. It wires the transport, starts the handshake, and begins pumping encrypted data. ([GitHub](https://github.com/holepunchto/hyperswarm-secret-stream/blob/main/index.js#L141))
- Example:

```js
const stream = new SecretStream(true, null, { autoStart: false })
stream.start(socket, { remotePublicKey })
```

#### `await stream.flush()`

[API definition on GitHub](https://github.com/holepunchto/hyperswarm-secret-stream/blob/main/index.js#L155)
- Signature: `await stream.flush()` ([GitHub](https://github.com/holepunchto/hyperswarm-secret-stream/blob/main/index.js#L155))
- Parameters: None. ([GitHub](https://github.com/holepunchto/hyperswarm-secret-stream/blob/main/index.js#L155))
- Returns: A promise resolving to `true` when pending encrypted writes and the underlying raw stream have flushed successfully, or `false` if the stream closed before that happened. ([GitHub](https://github.com/holepunchto/hyperswarm-secret-stream/blob/main/index.js#L164))
- Example:

```js
stream.write(Buffer.from('hello'))
await stream.flush()
```

### Stream configuration

#### `stream.setTimeout(ms)`

[API definition on GitHub](https://github.com/holepunchto/hyperswarm-secret-stream/blob/main/index.js#L93)
- Signature: `stream.setTimeout(ms)` ([GitHub](https://github.com/holepunchto/hyperswarm-secret-stream/blob/main/index.js#L93))
- Parameters: `ms` is the idle timeout in milliseconds. Use `0` to disable the timeout. ([GitHub](https://github.com/holepunchto/hyperswarm-secret-stream/blob/main/index.js#L93))
- Returns: Nothing. When the timer expires without inbound data, the stream destroys itself with a timeout error. ([GitHub](https://github.com/holepunchto/hyperswarm-secret-stream/blob/main/index.js#L99))
- Example:

```js
stream.setTimeout(30_000)
```

#### `stream.setKeepAlive(ms)`

[API definition on GitHub](https://github.com/holepunchto/hyperswarm-secret-stream/blob/main/index.js#L105)
- Signature: `stream.setKeepAlive(ms)` ([GitHub](https://github.com/holepunchto/hyperswarm-secret-stream/blob/main/index.js#L105))
- Parameters: `ms` is the heartbeat interval in milliseconds. Use `0` to disable keepalives. ([GitHub](https://github.com/holepunchto/hyperswarm-secret-stream/blob/main/index.js#L105))
- Returns: Nothing. The stream will periodically send empty encrypted frames while idle. ([GitHub](https://github.com/holepunchto/hyperswarm-secret-stream/blob/main/index.js#L112))
- Example:

```js
stream.setKeepAlive(10_000)
```

#### `stream.sendKeepAlive()`

[API definition on GitHub](https://github.com/holepunchto/hyperswarm-secret-stream/blob/main/index.js#L118)
- Signature: `stream.sendKeepAlive()` ([GitHub](https://github.com/holepunchto/hyperswarm-secret-stream/blob/main/index.js#L118))
- Parameters: None. ([GitHub](https://github.com/holepunchto/hyperswarm-secret-stream/blob/main/index.js#L118))
- Returns: Nothing. Immediately writes one empty encrypted keepalive frame. ([GitHub](https://github.com/holepunchto/hyperswarm-secret-stream/blob/main/index.js#L118))
- Example:

```js
stream.sendKeepAlive()
```

### Unordered messages

#### `await stream.send(buffer)`

[API definition on GitHub](https://github.com/holepunchto/hyperswarm-secret-stream/blob/main/index.js#L565)
- Signature: `await stream.send(buffer)` ([GitHub](https://github.com/holepunchto/hyperswarm-secret-stream/blob/main/index.js#L565))
- Parameters: `buffer` is the unordered datagram payload to encrypt. ([GitHub](https://github.com/holepunchto/hyperswarm-secret-stream/blob/main/index.js#L565))
- Returns: A promise when the underlying raw stream supports `send(...)` semantics, or `undefined` when unordered sending is unavailable. Messages sent before handshake completion are silently dropped. ([GitHub](https://github.com/holepunchto/hyperswarm-secret-stream/blob/main/index.js#L570))
- Example:

```js
await stream.opened
await stream.send(Buffer.from('unordered ping'))
```

#### `stream.trySend(buffer)`

[API definition on GitHub](https://github.com/holepunchto/hyperswarm-secret-stream/blob/main/index.js#L573)
- Signature: `stream.trySend(buffer)` ([GitHub](https://github.com/holepunchto/hyperswarm-secret-stream/blob/main/index.js#L573))
- Parameters: `buffer` is the unordered datagram payload to encrypt. ([GitHub](https://github.com/holepunchto/hyperswarm-secret-stream/blob/main/index.js#L573))
- Returns: Nothing. It attempts a best-effort unordered send when the underlying transport supports `trySend(...)`. ([GitHub](https://github.com/holepunchto/hyperswarm-secret-stream/blob/main/index.js#L575))
- Example:

```js
stream.trySend(Buffer.from('fire-and-forget'))
```

- Parameters: `listener` receives decrypted unordered messages as `Buffer` instances. ([GitHub](https://github.com/holepunchto/hyperswarm-secret-stream/blob/main/index.js#L435))

### Utility methods

#### `const buffer = stream.alloc(length)`

[API definition on GitHub](https://github.com/holepunchto/hyperswarm-secret-stream/blob/main/index.js#L604)
- Signature: `const buffer = stream.alloc(length)` ([GitHub](https://github.com/holepunchto/hyperswarm-secret-stream/blob/main/index.js#L604))
- Parameters: `length` is the ordered payload size you want to write next. ([GitHub](https://github.com/holepunchto/hyperswarm-secret-stream/blob/main/index.js#L604))

- Example:

```js

```

### Static helpers

#### `const keyPair = SecretStream.keyPair([seed])`

[API definition on GitHub](https://github.com/holepunchto/hyperswarm-secret-stream/blob/main/index.js#L85)
- Signature: `const keyPair = SecretStream.keyPair([seed])` ([GitHub](https://github.com/holepunchto/hyperswarm-secret-stream/blob/main/index.js#L85))
- Parameters: `seed` is an optional 32-byte seed for deterministic key generation. ([GitHub](https://github.com/holepunchto/hyperswarm-secret-stream/blob/main/index.js#L85))
- Returns: An ed25519 `{ publicKey, secretKey }` pair suitable for the Noise handshake. ([GitHub](https://github.com/holepunchto/hyperswarm-secret-stream/blob/main/index.js#L86))
- Example:

```js
const keyPair = SecretStream.keyPair()
```

#### `const id = SecretStream.id(handshakeHash, isInitiator, [out])`

[API definition on GitHub](https://github.com/holepunchto/hyperswarm-secret-stream/blob/main/index.js#L89)
- Signature: `const id = SecretStream.id(handshakeHash, isInitiator, [out])` ([GitHub](https://github.com/holepunchto/hyperswarm-secret-stream/blob/main/index.js#L89))
- Parameters: `handshakeHash` is the completed handshake hash, `isInitiator` chooses the initiator/responder namespace, and `out` optionally supplies an output buffer. ([GitHub](https://github.com/holepunchto/hyperswarm-secret-stream/blob/main/index.js#L89))
- Returns: A 32-byte stream identity derived from the handshake. ([GitHub](https://github.com/holepunchto/hyperswarm-secret-stream/blob/main/index.js#L90))
- Example:

```js
await stream.opened
const id = SecretStream.id(stream.handshakeHash, stream.isInitiator)
```
