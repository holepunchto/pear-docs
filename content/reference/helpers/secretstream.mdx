`Secretstream` wraps a transport stream in a Noise handshake plus libsodium `secretstream` encryption. It is the encrypted stream layer used underneath [Hyperswarm](/reference/building-blocks/hyperswarm) and related peer transports. For the upstream package, source, and release notes, see the [@hyperswarm/secret-stream repository](https://github.com/holepunchto/hyperswarm-secret-stream).

## Install

```sh
npm i @hyperswarm/secret-stream
```

## Quickstart

```js
import SecretStream from '@hyperswarm/secret-stream'

const a = new SecretStream(true)
const b = new SecretStream(false)

a.rawStream.pipe(b.rawStream).pipe(a.rawStream)

a.write(Buffer.from('hello encrypted world'))

b.on('data', (data) => {
  console.log(data.toString())
})
```

## API Reference

### Constructor and lifecycle

#### `const stream = new SecretStream(isInitiator, [rawStream], [options])`

- Signature: `const stream = new SecretStream(isInitiator, [rawStream], [options])`
- Parameters: `isInitiator` is `true` for the dialing side and `false` for the accepting side. `rawStream` is an optional underlying transport stream. `options.pattern` overrides the Noise pattern, `remotePublicKey` pins the remote identity when the pattern requires it, `keyPair` provides a local key pair or a promise resolving to one, `handshake` injects an already-computed handshake, `enableSend` disables unordered UDP-style sends when set to `false`, `keepAlive` configures heartbeat writes, and `autoStart` defaults to `true`.
- Returns: A duplex encrypted stream. You can use it like a normal stream for ordered reads and writes once the handshake completes.
- Example:

```js
const socket = getTransportSocketSomehow()
const stream = new SecretStream(true, socket, {
  keepAlive: 10_000
})
```

#### `stream.start([rawStream], [options])`

- Signature: `stream.start([rawStream], [options])`
- Parameters: `rawStream` is the transport to wrap when `autoStart: false` was used. `options` accepts the same handshake-related fields as the constructor, including `keyPair`, `handshake`, `data`, and `ended`.
- Returns: Nothing. It wires the transport, starts the handshake, and begins pumping encrypted data.
- Example:

```js
const stream = new SecretStream(true, null, { autoStart: false })
stream.start(socket, { remotePublicKey })
```

#### `await stream.flush()`

- Signature: `await stream.flush()`
- Parameters: None.
- Returns: A promise resolving to `true` when pending encrypted writes and the underlying raw stream have flushed successfully, or `false` if the stream closed before that happened.
- Example:

```js
stream.write(Buffer.from('hello'))
await stream.flush()
```

### Stream configuration

#### `stream.setTimeout(ms)`

- Signature: `stream.setTimeout(ms)`
- Parameters: `ms` is the idle timeout in milliseconds. Use `0` to disable the timeout.
- Returns: Nothing. When the timer expires without inbound data, the stream destroys itself with a timeout error.
- Example:

```js
stream.setTimeout(30_000)
```

#### `stream.setKeepAlive(ms)`

- Signature: `stream.setKeepAlive(ms)`
- Parameters: `ms` is the heartbeat interval in milliseconds. Use `0` to disable keepalives.
- Returns: Nothing. The stream will periodically send empty encrypted frames while idle.
- Example:

```js
stream.setKeepAlive(10_000)
```

#### `stream.sendKeepAlive()`

- Signature: `stream.sendKeepAlive()`
- Parameters: None.
- Returns: Nothing. Immediately writes one empty encrypted keepalive frame.
- Example:

```js
stream.sendKeepAlive()
```

### Ordered stream I/O

#### `stream.write(buffer)`

- Signature: `stream.write(buffer)`
- Parameters: `buffer` is the ordered payload to encrypt and send through the duplex stream.
- Returns: The usual writable-stream backpressure boolean.
- Example:

```js
stream.write(Buffer.from('ordered payload'))
```

#### `stream.end([buffer])`

- Signature: `stream.end([buffer])`
- Parameters: `buffer` is an optional final ordered payload.
- Returns: The stream instance, following standard writable-stream behavior.
- Example:

```js
stream.end(Buffer.from('goodbye'))
```

#### `stream.on('data', listener)`

- Signature: `stream.on('data', listener)`
- Parameters: `listener` receives ordered decrypted payloads as `Buffer` instances.
- Returns: The stream itself.
- Example:

```js
stream.on('data', (data) => {
  console.log(data.toString())
})
```

### Unordered messages

#### `await stream.send(buffer)`

- Signature: `await stream.send(buffer)`
- Parameters: `buffer` is the unordered datagram payload to encrypt.
- Returns: A promise when the underlying raw stream supports `send(...)` semantics, or `undefined` when unordered sending is unavailable. Messages sent before handshake completion are silently dropped.
- Example:

```js
await stream.opened
await stream.send(Buffer.from('unordered ping'))
```

#### `stream.trySend(buffer)`

- Signature: `stream.trySend(buffer)`
- Parameters: `buffer` is the unordered datagram payload to encrypt.
- Returns: Nothing. It attempts a best-effort unordered send when the underlying transport supports `trySend(...)`.
- Example:

```js
stream.trySend(Buffer.from('fire-and-forget'))
```

#### `stream.on('message', listener)`

- Signature: `stream.on('message', listener)`
- Parameters: `listener` receives decrypted unordered messages as `Buffer` instances.
- Returns: The stream itself.
- Example:

```js
stream.on('message', (message) => {
  console.log(message.toString())
})
```

### Utility methods

#### `const buffer = stream.alloc(length)`

- Signature: `const buffer = stream.alloc(length)`
- Parameters: `length` is the ordered payload size you want to write next.
- Returns: A writable payload slice backed by a preallocated encrypted output buffer. Write into it, then pass it to `stream.write(...)`.
- Example:

```js
const payload = stream.alloc(5)
payload.set(Buffer.from('hello'))
stream.write(payload)
```

#### `const json = stream.toJSON()`

- Signature: `const json = stream.toJSON()`
- Parameters: None.
- Returns: A diagnostic object containing connection state, keys, and any serializable raw-stream metadata.
- Example:

```js
console.log(stream.toJSON())
```

### Static helpers

#### `const keyPair = SecretStream.keyPair([seed])`

- Signature: `const keyPair = SecretStream.keyPair([seed])`
- Parameters: `seed` is an optional 32-byte seed for deterministic key generation.
- Returns: An ed25519 `{ publicKey, secretKey }` pair suitable for the Noise handshake.
- Example:

```js
const keyPair = SecretStream.keyPair()
```

#### `const id = SecretStream.id(handshakeHash, isInitiator, [out])`

- Signature: `const id = SecretStream.id(handshakeHash, isInitiator, [out])`
- Parameters: `handshakeHash` is the completed handshake hash, `isInitiator` chooses the initiator/responder namespace, and `out` optionally supplies an output buffer.
- Returns: A 32-byte stream identity derived from the handshake.
- Example:

```js
await stream.opened
const id = SecretStream.id(stream.handshakeHash, stream.isInitiator)
```

### Public properties

#### `stream.isInitiator`

- Returns: `true` on the dialing side and `false` on the accepting side.

#### `stream.rawStream`

- Returns: The wrapped transport stream, or a bridge stream when no raw stream was supplied up front.

#### `stream.publicKey`

- Returns: The local public key used in the handshake.

#### `stream.remotePublicKey`

- Returns: The remote peer's public key after the handshake succeeds.

#### `stream.handshakeHash`

- Returns: The Noise handshake hash after the encrypted session is established.

#### `stream.connected`

- Returns: `true` once the handshake is complete and the stream has emitted `connect`.

#### `stream.keepAlive`

- Returns: The configured keepalive interval in milliseconds.

#### `stream.timeout`

- Returns: The configured idle-timeout interval in milliseconds.

#### `stream.enableSend`

- Returns: `true` when unordered `send(...)` and `trySend(...)` support is enabled.

#### `stream.opened`

- Returns: A promise that resolves to `true` when the handshake succeeds, or `false` if the stream closes before opening.

#### `stream.rawBytesWritten`

- Returns: The total encrypted byte count written to the raw stream.

#### `stream.rawBytesRead`

- Returns: The total encrypted byte count read from the raw stream before decryption.

#### `stream.userData`

- Returns: An arbitrary user-controlled field that higher-level protocols often use to attach transport metadata.

### Events

#### `stream.on('connect', listener)`

- Signature: `stream.on('connect', listener)`
- Parameters: `listener` fires once the handshake is complete and ordered writes are fully active.
- Returns: The stream itself.
- Example:

```js
stream.on('connect', () => {
  console.log(stream.remotePublicKey)
})
```

#### `stream.on('handshake', listener)`

- Signature: `stream.on('handshake', listener)`
- Parameters: `listener` fires when the Noise handshake keys and hash have been established.
- Returns: The stream itself.
- Example:

```js
stream.on('handshake', () => {
  console.log(stream.handshakeHash)
})
```
