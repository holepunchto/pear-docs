`Corestore` manages many related [Hypercores](/reference/building-blocks/hypercore) behind one storage root and one replication surface. It is the helper you usually share across [Hyperbee](/reference/building-blocks/hyperbee), [Hyperdrive](/reference/building-blocks/hyperdrive), and [Autobase](/reference/building-blocks/autobase) instances. For upstream source and changelog context, see the [Corestore repository](https://github.com/holepunchto/corestore).

## Install

```sh
npm i corestore
```

## Quickstart

```js
import Corestore from 'corestore'

const store = new Corestore('./app-storage')
await store.ready()

const messages = store.get({
  name: 'messages',
  valueEncoding: 'json'
})

await messages.ready()
await messages.append({ text: 'hello from corestore' })

console.log(await messages.get(0))

await store.close()
```

## API Reference

### Constructor and lifecycle

#### `const store = new Corestore(storage, [options])`

[API definition on GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L234)
- Signature: `const store = new Corestore(storage, [options])` ([GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L234))
- Parameters: `storage` is either a local path string or a `hypercore-storage` instance. `options` can include `primaryKey`, `writable`, `readOnly`, `globalCache`, `manifestVersion`, `id`, `allowBackup`, `wait`, `suspend`, `active`, and `unsafe` when you intentionally pass a custom `primaryKey`. ([GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L234))
- Returns: A `Corestore` instance that lazily opens its underlying storage and derives writable core keys from one root key. ([GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L431))
- Example:

```js
const store = new Corestore('./storage', {
  manifestVersion: 1,
  writable: true
})

await store.ready()
```

#### `await store.ready()`

[API definition on GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L271)
- Signature: `await store.ready()` ([GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L271))
- Parameters: None. ([GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L271))
- Returns: A promise that resolves once the storage seed is loaded and properties such as `store.primaryKey` are available. ([GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L271))
- Example:

```js
await store.ready()
console.log(store.primaryKey)
```

#### `await store.close()`

[API definition on GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L182)
- Signature: `await store.close()` ([GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L182))
- Parameters: None. ([GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L182))
- Returns: A promise that resolves after all open sessions, cores, and underlying storage handles managed by this store are closed. ([GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L193))
- Example:

```js
await store.close()
```

#### `await store.suspend([options])`

[API definition on GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L309)
- Signature: `await store.suspend([options])` ([GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L309))
- Parameters: `options.log` is an optional async logger callback that receives progress messages such as `"Flushing db..."` and `"Suspending db..."`. ([GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L309))
- Returns: A promise that resolves after the backing database has been flushed and, when supported, suspended. ([GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L313))
- Example:

```js
await store.suspend({
  async log(message) {
    console.log(message)
  }
})
```

#### `await store.resume()`

[API definition on GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L107)
- Signature: `await store.resume()` ([GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L107))
- Parameters: None. ([GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L107))
- Returns: A promise that resolves after a suspended backing store is resumed. ([GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L121))
- Example:

```js
await store.resume()
```

### Store properties

#### `store.storage`

[API definition on GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L239)
- Returns: The backing storage adapter used for aliases, seeds, and Hypercore data files. ([GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L239))

#### `store.primaryKey`

[API definition on GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L253)
- Returns: The 32-byte primary key used to deterministically derive writable named cores and namespaced key pairs. ([GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L253))

#### `store.readOnly`

[API definition on GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L251)
- Returns: `true` when the store was opened without write access. ([GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L251))

#### `store.manifestVersion`

[API definition on GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L255)
- Returns: The Hypercore manifest version used when Corestore creates new writable cores. ([GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L255))

#### `store.active`

[API definition on GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L257)
- Returns: `true` when the store should automatically attach loaded cores to active replication streams. ([GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L257))

### Loading cores and scoping sessions

#### `const core = store.get(keyOrOptions)`

[API definition on GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L58)
- Signature: `const core = store.get(keyOrOptions)` ([GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L58))
- Parameters: Pass a raw core key, discovery key, or an options object. Common options are `name`, `key`, `discoveryKey`, `valueEncoding`, `encryption`, `manifest`, `keyPair`, `writable`, `timeout`, `wait`, `active`, and any Hypercore constructor options that should flow into the resulting session. ([GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L58))
- Returns: A `Hypercore` session. Repeated calls for the same underlying core reuse the same loaded resources and hand back new sessions. ([GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L63))
- Example:

```js
const writer = store.get({ name: 'messages', valueEncoding: 'json' })
await writer.ready()

const reader = store.get(writer.key)
await reader.ready()
```

#### `const sessionStore = store.session([options])`

[API definition on GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L322)
- Signature: `const sessionStore = store.session([options])` ([GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L322))
- Parameters: `options` can override session-level flags such as `namespace`, `active`, or `manifestVersion`. ([GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L322))
- Returns: A child `Corestore` session that shares the same underlying storage and primary key, but tracks its own opened cores. Closing the session closes the cores created through that session only. ([GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L325))
- Example:

```js
const sessionStore = store.session()
const sessionCore = sessionStore.get({ name: 'session-only' })

await sessionCore.ready()
await sessionStore.close()
```

#### `const namespacedStore = store.namespace(name, [options])`

[API definition on GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L332)
- Signature: `const namespacedStore = store.namespace(name, [options])` ([GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L332))
- Parameters: `name` is the namespace label to hash into the key-derivation namespace. `options` are forwarded to `store.session(...)`. ([GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L332))
- Returns: A child `Corestore` session whose named writable cores do not collide with the parent or sibling namespaces. ([GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L333))
- Example:

```js
const appStore = store.namespace('my-app')
const jobsStore = store.namespace('jobs')

const appCore = appStore.get({ name: 'main' })
const jobsCore = jobsStore.get({ name: 'main' })
```

### Replication and discovery

#### `const stream = store.replicate(isInitiatorOrStream, [options])`

[API definition on GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L436)
- Signature: `const stream = store.replicate(isInitiatorOrStream, [options])` ([GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L436))
- Parameters: Pass either a boolean initiator flag or an existing protocol stream/socket. `options` are forwarded to Hypercore's protocol-stream creation, including transport-specific replication settings. ([GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L436))
- Returns: A protocol stream that can replicate every compatible core currently opened through the store, plus newly opened ones while the stream stays attached. ([GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L466))
- Example:

```js
swarm.on('connection', (socket) => {
  store.replicate(socket)
})
```

#### `const done = store.findingPeers()`

[API definition on GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L294)
- Signature: `const done = store.findingPeers()` ([GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L294))
- Parameters: None. ([GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L294))
- Returns: A completion callback. Call it after the current peer-discovery pass finishes so pending update waits on loaded cores can unblock. ([GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L299))
- Example:

```js
const done = store.findingPeers()
swarm.flush().then(done, done)
```

#### `const stream = store.list([namespace])`

[API definition on GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L70)
- Signature: `const stream = store.list([namespace])` ([GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L70))
- Parameters: `namespace` optionally narrows the listing to one derived namespace buffer. ([GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L70))
- Returns: A stream of discovery keys for the cores known to the backing store. ([GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L71))
- Example:

```js
for await (const discoveryKey of store.list()) {
  console.log(discoveryKey)
}
```

#### `const auth = store.getAuth(discoveryKey)`

[API definition on GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L343)
- Signature: `const auth = store.getAuth(discoveryKey)` ([GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L343))
- Parameters: `discoveryKey` is the discovery key for a stored core. ([GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L343))
- Returns: The storage-layer auth metadata for that core, including manifest details when available. ([GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L344))
- Example:

```js
const auth = store.getAuth(core.discoveryKey)
console.log(auth)
```

### Key derivation and maintenance

#### `const keyPair = await store.createKeyPair(name, [namespace])`

[API definition on GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L575)
- Signature: `const keyPair = await store.createKeyPair(name, [namespace])` ([GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L575))
- Parameters: `name` is the deterministic label to derive from the store primary key. `namespace` optionally overrides the current namespace buffer instead of using `store.ns`. ([GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L575))
- Returns: A deterministic `{ publicKey, secretKey }` pair derived from the store seed and namespace. ([GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L577))
- Example:

```js
const keyPair = await store.createKeyPair('peer-rpc')
console.log(keyPair.publicKey)
```

#### `const report = await store.audit([options])`

[API definition on GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L305)
- Signature: `const report = await store.audit([options])` ([GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L305))
- Parameters: `options` are forwarded to Corestore's audit helper. ([GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L305))
- Returns: An audit report describing the state of the backing store and any detected inconsistencies. ([GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L306))
- Example:

```js
const report = await store.audit()
console.log(report)
```

#### `const staticCore = await store.staticify(core, [options])`

[API definition on GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L475)
- Signature: `const staticCore = await store.staticify(core, [options])` ([GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L475))
- Parameters: `core` is an opened Hypercore with data. `options` are forwarded to the follow-up `store.get(...)` call used to reopen the staticized core. ([GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L475))
- Returns: A reopened Hypercore whose manifest is converted into a static prologue-based manifest for the current data snapshot. ([GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L516))
- Example:

```js
const liveCore = store.get({ name: 'docs' })
await liveCore.ready()
await liveCore.append('snapshot me')

const staticCore = await store.staticify(liveCore)
await staticCore.ready()
```

### Watchers

#### `store.watch(callback)`

[API definition on GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L95)
- Signature: `store.watch(callback)` ([GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L95))
- Parameters: `callback` receives each newly opened internal core object. ([GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L95))
- Returns: Nothing. The callback stays registered until you call `store.unwatch(callback)` or close the store. ([GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L96))
- Example:

```js
function onopen(core) {
  console.log(core.discoveryKey)
}

store.watch(onopen)
```

#### `store.unwatch(callback)`

[API definition on GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L100)
- Signature: `store.unwatch(callback)` ([GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L100))
- Parameters: `callback` is the same function previously passed to `store.watch(...)`. ([GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L100))
- Returns: Nothing. ([GitHub](https://github.com/holepunchto/corestore/blob/main/index.js#L101))
- Example:

```js
store.unwatch(onopen)
```
