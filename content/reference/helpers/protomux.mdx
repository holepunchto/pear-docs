<Status level="stable" />

`Protomux` multiplexes multiple message-oriented subprotocols over one framed stream. It is typically layered on top of [Secretstream](/reference/helpers/secretstream) and uses [Compact encoding](/reference/helpers/compact-encoding) for message schemas. For source and releases, see the [Protomux repository](https://github.com/holepunchto/protomux).

## Install

```sh
npm i protomux
```

## Quickstart

```js
import Protomux from 'protomux'
import cenc from 'compact-encoding'

const mux = new Protomux(aFramedEncryptedStream)

const channel = mux.createChannel({
  protocol: 'chat',
  onopen() {
    console.log('chat channel opened')
  }
})

const message = channel.addMessage({
  encoding: cenc.string,
  onmessage(text) {
    console.log(text)
  }
})

channel.open()
message.send('hello')
```

## API Reference

### Constructor and mux helpers

#### `mux = new Protomux(stream, [options])`

[src](https://github.com/holepunchto/protomux/blob/v3.11.0/index.js#L331)

Make a new instance. `stream` should be a framed stream, preserving the messages written.

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `stream` | `object` | — | — |
| `options` | [`ProtomuxOptions`](#protomuxoptions) | `{}` | Optional configuration for the instance, such as a custom buffer allocator. |

```js
{
  // Called when the muxer wants to allocate a message that is written, defaults to Buffer.allocUnsafe.
  alloc (size) {}
}
```

#### `mux = Protomux.from(stream | muxer, [options])`

[src](https://github.com/holepunchto/protomux/blob/v3.11.0/index.js#L365)

Helper to accept either an existing muxer instance or a stream (which creates a new one).

| Parameter | Type | Description |
| --- | --- | --- |
| `stream` | `object` | A framed stream or an existing Protomux instance. |
| `opts` | [`ProtomuxOptions`](#protomuxoptions) | Muxer options passed through when a new instance is created. |

- Returns: [`Protomux`](/reference/helpers/protomux) — The existing or newly created Protomux instance.

```js
const mux = Protomux.from(someStream)
```

#### `Protomux.isProtomux(mux)`

[src](https://github.com/holepunchto/protomux/blob/v3.11.0/index.js#L371)

Returns `true` when `value` looks like a Protomux instance.

| Parameter | Type | Description |
| --- | --- | --- |
| `mux` | `object` | Value to test. |

- Returns: `boolean` — `true` when `mux` is a Protomux instance.

```js
Protomux.isProtomux(mux) // true
Protomux.isProtomux({})  // false
```

#### `mux.cork()`

[src](https://github.com/holepunchto/protomux/blob/v3.11.0/index.js#L385)

Same as `channel.cork` but on the muxer instance.

- Returns: `void`

```js
mux.cork()
channelA.messages[0].send('hello')
channelB.messages[0].send('world')
mux.uncork() // sends both as one frame
```

#### `mux.uncork()`

[src](https://github.com/holepunchto/protomux/blob/v3.11.0/index.js#L392)

Same as `channel.uncork` but on the muxer instance.

- Returns: `void`

```js
mux.cork()
msg.send('hello')
mux.uncork()
```

#### `mux.isIdle()`

[src](https://github.com/holepunchto/protomux/blob/v3.11.0/index.js#L381)

Convenience method that returns true if the number of channels is currently 0.

- Returns: `boolean` — `true` if the channel count is currently zero.

```js
if (mux.isIdle()) console.log('no open channels')
```

#### `for (const channel of muxer) { ... }`

The muxer instance is iterable, so you can iterate over all the channels.

### Pairing and channel discovery

#### `mux.pair({ protocol, id }, callback)`

[src](https://github.com/holepunchto/protomux/blob/v3.11.0/index.js#L407)

Register a callback to be called everytime a new channel is requested.

| Parameter | Type | Description |
| --- | --- | --- |
| `options` | [`ChannelKey`](#channelkey) | Protocol name and optional binary id to match. |
| `notify` | `Function` | Async callback called with the channel's binary id when a matching remote channel opens. |

- Returns: `void`

```js
mux.pair({ protocol: 'my-protocol' }, async (id) => {
  const channel = mux.createChannel({ protocol: 'my-protocol' })
  channel.open()
})
```

#### `mux.unpair({ protocol, id })`

[src](https://github.com/holepunchto/protomux/blob/v3.11.0/index.js#L411)

Unregisters the pair callback.

| Parameter | Type | Description |
| --- | --- | --- |
| `options` | [`ChannelKey`](#channelkey) | Protocol name and optional binary id to deregister. |

- Returns: `void`

```js
mux.unpair({ protocol: 'my-protocol' })
```

#### `mux.opened({ protocol, id })`

[src](https://github.com/holepunchto/protomux/blob/v3.11.0/index.js#L415)

Boolean that indicates if the channel is opened.

| Parameter | Type | Description |
| --- | --- | --- |
| `options` | [`ChannelKey`](#channelkey) | Protocol name and optional binary id to check. |

- Returns: `boolean` — `true` when one or more matching channels are open.

```js
if (mux.opened({ protocol: 'my-protocol' })) {
  console.log('already open')
}
```

#### `mux.getLastChannel(options)`

[src](https://github.com/holepunchto/protomux/blob/v3.11.0/index.js#L400)

Returns the most recently opened matching channel, or `null` if none is open.

| Parameter | Type | Description |
| --- | --- | --- |
| `options` | [`ChannelKey`](#channelkey) | Protocol name and optional binary id. |

- Returns: [`Channel\|null`](/reference/helpers/protomux) — The most recently opened matching channel, or `null`.

```js
const ch = mux.getLastChannel({ protocol: 'my-protocol' })
```

### Channel lifecycle

#### `channel.open([handshake])`

[src](https://github.com/holepunchto/protomux/blob/v3.11.0/index.js#L87)

Open the channel.

| Parameter | Type | Description |
| --- | --- | --- |
| `handshake` | `*` | Optional handshake value encoded with the handshake encoding provided to `createChannel`. |

- Returns: `void`

```js
const channel = mux.createChannel({ protocol: 'my-protocol' })
channel.open()
```

#### `channel.fullyOpened()`

[src](https://github.com/holepunchto/protomux/blob/v3.11.0/index.js#L66)

Resolves to `true` when the channel fully opens or `false` if it closes first.

- Returns: [`Promise<boolean>`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Promise)

```js
const opened = await channel.fullyOpened()
if (opened) console.log('channel is open')
```

#### `channel.fullyClosed()`

[src](https://github.com/holepunchto/protomux/blob/v3.11.0/index.js#L77)

Resolves once the channel has been destroyed and all pending async handlers have finished.

- Returns: [`Promise<void>`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Promise)

```js
await channel.fullyClosed()
console.log('channel destroyed')
```

#### `channel.close()`

[src](https://github.com/holepunchto/protomux/blob/v3.11.0/index.js#L242)

Closes the protocol channel.

- Returns: `void`

```js
channel.close()
```

#### `channel.cork()`

[src](https://github.com/holepunchto/protomux/blob/v3.11.0/index.js#L234)

Corking the protocol channel, makes it buffer messages and send them all in a batch when it uncorks.

- Returns: `void`

```js
channel.cork()
one.send('hello')
two.send(true)
channel.uncork() // sends both as a single batch
```

#### `channel.uncork()`

[src](https://github.com/holepunchto/protomux/blob/v3.11.0/index.js#L238)

Uncork and send the batch.

- Returns: `void`

```js
channel.cork()
one.send('hello')
channel.uncork()
```

### Lifecycle callbacks

#### `channel.onopen`

[src](https://github.com/holepunchto/protomux/blob/v3.11.0/index.js#L37)

- Returns: Called when the channel opens. `handshake` is the decoded open payload or `null`, and `channel` is the channel instance.

#### `channel.onclose`

[src](https://github.com/holepunchto/protomux/blob/v3.11.0/index.js#L38)

- Returns: Called when the channel closes. `isRemote` is `true` when the remote side initiated the close, and `channel` is the channel instance.

#### `channel.ondestroy`

[src](https://github.com/holepunchto/protomux/blob/v3.11.0/index.js#L39)

- Returns: Called when the channel is destroyed. `channel` is the destroyed channel instance.

#### `channel.ondrain`

[src](https://github.com/holepunchto/protomux/blob/v3.11.0/index.js#L40)

- Returns: Called when the channel's underlying mux becomes writable again. `channel` is that channel instance.

## Types

### ProtomuxOptions

Options for allocating buffers in a Protomux instance.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `alloc` | `Function` | — | Custom allocator; called with `(size)` and must return a `Buffer`. Defaults to `Buffer.allocUnsafe`. |

### CreateChannelOptions

Options for creating a protocol channel.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `protocol` | `string` | — | Protocol name used to match channels between peers. |
| `id` | [`Buffer\|null`](https://nodejs.org/api/buffer.html#class-buffer) | `null` | Optional binary identifier to distinguish multiple channels with the same protocol name. |
| `handshake` | `*` | `null` | Compact-encoding codec for encoding/decoding the handshake value exchanged on open. |
| `messages` | [`Array<AddMessageOptions>`](#addmessageoptions) | `[]` | Array of message descriptors registered on channel open. |
| `unique` | `boolean` | `true` | When `true`, returns `null` if a channel with this protocol+id is already open. |
| `aliases` | [`Array<string>`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array) | `[]` | Alternative protocol names that also match this channel. |
| `userData` | `*` | `null` | Arbitrary value stored as `channel.userData`; not transmitted. |
| `onopen` | `Function` | — | Called with `(handshake, channel)` when the remote side opens this protocol. |
| `onclose` | `Function` | — | Called with `(isRemote, channel)` when either side closes the channel. |
| `ondestroy` | `Function` | — | Called with `(channel)` after `onclose` resolves and all pending promises settle. |
| `ondrain` | `Function` | — | Called with `(channel)` when the underlying stream drains. |

### AddMessageOptions

Options for registering a message type on a channel.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `encoding` | `object` | — | A compact-encoding codec. Defaults to raw binary (`c.raw`). |
| `autoBatch` | `boolean` | `true` | When `true`, batch replies are collected before the next tick. |
| `onmessage` | `Function` | — | Called with `(message, channel)` when the remote sends a message of this type. |

### ChannelKey

Protocol + id selector used by pair/unpair/opened/getLastChannel.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `protocol` | `string` | — | Protocol name to match. |
| `id` | [`Buffer\|null`](https://nodejs.org/api/buffer.html#class-buffer) | `null` | Optional binary id to narrow the match. |
