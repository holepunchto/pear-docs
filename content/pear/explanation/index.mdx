Pear is a platform for building, distributing, and updating applications that run peer-to-peer. A Pear app is an ordinary Electron, React Native, or standalone [Bare](/bare) program whose peer-to-peer core finds other users directly, keeps data on the user's own device, and pulls its own updates from the peers already running it. The `pear` CLI stages and releases builds; the [`pear-runtime`](/pear/reference/pear/runtime) library inside the app receives them. There is no server in that picture because there is no server.

The pages in this section are for understanding, not doing. They answer "why" rather than "how": why Pear treats an app as replicated data, where that data lives on disk, why peer-to-peer logic runs in a Bare worker rather than the UI process, and why a release goes through stage, provision, and multisig instead of a single deploy.

If you want to build something, head to **[Getting started](/pear/getting-started)** or **[How To](/pear/how-to)**. If you need to look up a specific API, that's **[Reference](/pear/reference)**.
