## In this section

### Pear

- [Pear CLI](/pear/reference/pear/cli)—covers `pear stage`, `pear seed`, `pear build`, `pear install`, and every flag.
- [Pear OTA](/pear/reference/pear/runtime)—the `pear-runtime` library and JavaScript API for over-the-air updates inside a running Pear app.
- [Configuration](/pear/reference/pear/configuration)—every key in `package.json`'s `pear` block.
- [Pear API (removed)](/pear/reference/pear/api)—the older direct-access `global.Pear` API, removed in v3. Use the Pear OTA (`pear-runtime`) module instead.

For a curated record of breaking changes and removals across these modules, see the [Release Overview](/pear/release-overview).

- [Bare Kit](/bare/reference/bare/bare-kit)—the Worklet and IPC API for iOS, Android, and React Native.

## Stability legend

Module pages call out a stability indicator. The four levels:

|                           Stability                                |                         Description                         |
| ------------------------------------------------------------------ | ----------------------------------------------------------- |
| <Status level="stable" />       | Unlikely to change or be removed in the foreseeable future.  |
| <Status level="experimental" /> | New, untested, or has known issues.                          |
| <Status level="deprecated" />   | Being removed or replaced in the future.                     |
| <Status level="unstable" />     | May change or be removed without warning.                    |
