## Which one?

- **Building a desktop GUI?** Start from [hello-pear-electron](/pear/getting-started/from-a-template/start-from-hello-pear-electron)—it ships a renderer and the preload bridge that connects your UI to peer-to-peer logic in a Bare worker.
- **Building a CLI, daemon, or other headless tool?** Start from [hello-pear-bare](/pear/getting-started/from-a-template/start-from-hello-pear-bare)—it compiles to a single standalone binary per OS and architecture.

Both share the same peer-to-peer core: the [Bare](/bare/reference/modules/bare-modules) runtime, [`pear-runtime`](/pear/reference/pear/runtime) for updates, and the [Hyperswarm](/bare/reference/building-blocks/hyperswarm) + [Corestore](/bare/reference/helpers/corestore) stack. Your peer-to-peer logic is portable between them—only the shell (GUI versus terminal) changes. See [Runtime and languages](/pear/explanation/runtime-and-languages).
