How-tos are goal-oriented recipes. Each one assumes you already know roughly what you're doing and just need the steps for a particular task—[replicating a Hypercore](/bare/how-to/store-and-replicate/replicate-and-persist-with-hypercore), [deploying an app](/pear/how-to/operate-an-app/manual-deployment/deployment), or [troubleshooting common issues](/pear/how-to/troubleshooting).

If you want to look up a CLI flag, an API, or a config field, that's **[Reference](/pear/reference)**. For the conceptual "why," see **[About Pear](/pear/explanation)**.

## Start here

Many recipes below build on one of two starting points. Chat-focused guides extend the **`pear-chat` scaffold** (Electron shell, Bare worker, [Autobase](/bare/reference/building-blocks/autobase)-backed chat room) built step by step in the **[Getting Started](/pear/getting-started)** path—see [Reshape into a production app](/pear/getting-started/build-a-peer-to-peer-chat/reshape-into-a-production-app). Guides that don't need chat start from one of the boilerplates in **[Start from a template](/pear/getting-started/from-a-template)**—desktop ([`hello-pear-electron`](/pear/getting-started/from-a-template/start-from-hello-pear-electron)) or terminal ([`hello-pear-bare`](/pear/getting-started/from-a-template/start-from-hello-pear-bare)). Each guide states its base up front. If you're new, work through Getting Started first so you understand each piece before adapting it.

## In this section

- [Browse commands with the interactive menu](/pear/how-to/browse-commands-with-the-interactive-menu)—find and run CLI commands from a filterable list and a form, instead of memorizing flags.
- [Manage installed applications](/pear/how-to/manage-installed-applications)—list installed Pear apps and reset their storage.
- [Troubleshoot common issues](/pear/how-to/troubleshooting)—fixes for common Pear and Bare development issues.

Several guides below extend a base scaffold—either the `pear-chat` app from the [Getting Started path](/pear/getting-started/build-a-peer-to-peer-chat/reshape-into-a-production-app) or a boilerplate from [Start from a template](/pear/getting-started/from-a-template)—with one capability at a time. They teach **Pear-end logic**—the code in the Bare [worker](/pear/explanation/workers), not the UI—so the same worker is portable across desktop, mobile, and terminal; only the UI half changes per platform (see [Runtime and languages](/pear/explanation/runtime-and-languages)).
