Pear is an installable peer-to-peer runtime, development, and deployment platform. Build, share, and extend unstoppable, zero-infrastructure P2P apps for mobile, desktop, and terminal.

Welcome to the Internet of Peers.

&nbsp; _– Holepunch, the P2P Company_

Pear runs on [Bare](/bare), the zero-core JavaScript runtime underneath it—which you can also use entirely on its own, embedded in a native app or compiled into a standalone binary. The peer-to-peer building blocks it ships with—Hypercore, Hyperswarm, Autobase, and the rest—are documented on the [P2P tab](/p2p) and work with or without Pear. [How the stack fits together](/p2p/explanation/how-the-stack-fits-together) maps the layers.

## Install Pear

Get the [`pear`](/pear/reference/pear/cli) CLI from **[install.pears.com](https://install.pears.com)**:

```sh
curl https://install.pears.com/pear.sh | sh
```

See [Getting started](/pear/getting-started#install-pear) for Windows, Homebrew, npx, and Docker installs. You only need the CLI to ship; building and running an app locally works with Node.js and npm alone.

## Module catalog

The full list of `pear-*` modules—application libraries, UI libraries, common libraries, developer libraries, integration libraries—lives at **[Reference → Modules](/pear/reference/modules/pear-modules)**. Building-block libraries ([Hypercore](/p2p/reference/building-blocks/hypercore), [Hyperbee](/p2p/reference/building-blocks/hyperbee), [Hyperdrive](/p2p/reference/building-blocks/hyperdrive), …), helpers ([Corestore](/p2p/reference/helpers/corestore), [Localdrive](/p2p/reference/helpers/localdrive), …), and CLI tools have full reference pages under **[P2P's Reference](/p2p/reference)**. The runtime underneath has its own reference—the [`bare-*` modules](/bare/reference/bare/modules), the [Bare runtime API](/bare/reference/bare/runtime), the [`bare` CLI](/bare/reference/bare/cli), and [Bare Kit](/bare/reference/bare/bare-kit) for native embedding.
