Pear is an installable peer-to-peer runtime, development, and deployment platform. Build, share, and extend unstoppable, zero-infrastructure P2P apps for mobile, desktop, and terminal.

Welcome to the Internet of Peers.

&nbsp; _– Holepunch, the P2P Company_

A four-part type-along that builds a peer-to-peer chat app with Electron, adds persistence with [Corestore](/reference/helpers/corestore), then ships and updates it. About 15 minutes for the first part; no clone required.

[**Start the type-along →**](/getting-started/build-a-peer-to-peer-chat/build-a-peer-to-peer-chat)

Prefer to start from a working template? [**Start from the `hello-pear-electron` and `hello-pear-bare`**](/getting-started/from-a-template/index) clones. The boilerplate and walks you through where the frontend, app logic, and preload bridge live before you add a feature end to end.

## Module catalog

Pear apps are suppored with `pear-*` and `bare-*` modules—application libraries. These are UI libraries, common libraries, developer libraries, and integration libraries—lives. Find the lists at **[Reference → Modules](/reference/modules/pear-modules)** and **[Reference → Bare modules](/reference/modules/bare-modules)**. Building-block libraries (Hypercore, Hyperbee, Hyperdrive, …), helpers (Corestore, Localdrive, …), and CLI tools have full reference pages under **[Reference](/reference)**.
