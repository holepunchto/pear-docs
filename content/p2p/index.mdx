P2P is the peer-to-peer building blocks: [Hypercore](/p2p/reference/building-blocks/hypercore) for append-only logs, [Hyperbee](/p2p/reference/building-blocks/hyperbee) and [Hyperdrive](/p2p/reference/building-blocks/hyperdrive) built on top of it, [Hyperswarm](/p2p/reference/building-blocks/hyperswarm) and [HyperDHT](/p2p/reference/building-blocks/hyperdht) for finding peers, [Autobase](/p2p/reference/building-blocks/autobase) for multi-writer collaboration, and [Corestore](/p2p/reference/helpers/corestore) for managing many cores at once. Each one is an ordinary JavaScript module with no special status—install it with npm and use it like any other dependency.

They run on [Bare](/bare), the zero-core JavaScript runtime, which is why the same storage and networking code works unchanged on desktop, mobile, or terminal. And they're what [Pear](/), the peer-to-peer platform, is built on top of—if you want to ship what you build here as an app with over-the-air updates, that's what Pear adds.
