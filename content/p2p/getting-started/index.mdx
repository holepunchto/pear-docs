The P2P building blocks are ordinary npm modules. You can use them in a Node.js script, a Bare program, or inside an app you already have, with no Pear CLI and no new runtime. This page is the shortest path to two processes finding each other and exchanging data, using nothing but those modules.

If what you want is a *shippable app*—a desktop or mobile program that updates itself over the swarm—start from [Pear's Getting started](/pear/getting-started) instead. It builds a complete chat app with these same modules and then releases it.

## Before you start

- [Node.js](https://nodejs.org/) v22.17 or newer and npm v10.9 or newer—or [Bare](/bare), installed with `npm i -g bare`. Every how-to below runs on either.
- A terminal and an editor.

That's all. The modules are installed per project with `npm install`.

## Connect two peers

The first thing every peer-to-peer program does is find another copy of itself. [Hyperswarm](/p2p/reference/building-blocks/hyperswarm) does that: peers join a topic—a 32-byte key—and the DHT introduces them to each other, through NATs and firewalls, with an end-to-end encrypted connection.

## Replicate data

A connection moves bytes. [Hypercore](/p2p/reference/building-blocks/hypercore) turns bytes into a signed append-only log that any peer can replicate and verify, and the rest of the building blocks are structures on top of it: a key-value store ([Hyperbee](/p2p/reference/building-blocks/hyperbee)), a filesystem ([Hyperdrive](/p2p/reference/building-blocks/hyperdrive)), and a multi-writer database ([Autobase](/p2p/reference/building-blocks/autobase)).

## Ship it with Pear

Nothing above needs Pear. Pear is what you add when the program should become an application other people install and that updates itself: the [`pear-runtime`](/pear/reference/pear/runtime) library runs your peer-to-peer core in a Bare worker inside an Electron or React Native app, and the `pear` CLI stages and releases it over the same swarm. [Pear's Getting started](/pear/getting-started) takes exactly that step, with a chat app built on Hyperswarm and Autobase. [How the stack fits together](/p2p/explanation/how-the-stack-fits-together) shows where the line between the two sits.
