Bare is a small, modular JavaScript runtime. Embed it in a native app, or compile a script into a single standalone binary—no Node.js, no peer-to-peer machinery, no Pear install required.

[Pear](/), the peer-to-peer platform, is built on Bare—see [How Pear and Bare fit together](/pear/explanation/pear-and-bare) if that's what brought you here. This tab is for using Bare entirely on its own.

## Install the Bare CLI

```sh
npm i -g bare
```

Run a script directly, or start a REPL with no script. Full flag reference: [Bare CLI](/bare/reference/bare/cli).

```sh
bare script.js
```
