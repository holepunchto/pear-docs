How-tos are goal-oriented recipes. Each one assumes you already know roughly what you're doing and just need the steps for a particular task—[connecting two peers with HyperDHT](/bare/how-to/connect-to-peers/connect-two-peers-by-key-with-hyperdht), [replicating with Hypercore](/bare/how-to/store-and-replicate/replicate-and-persist-with-hypercore), or [porting an existing Node.js app](/bare/how-to/migrate-a-nodejs-app-to-bare).

If you want to look up an API or a module, that's **[Reference](/bare/reference)**. For the conceptual "why," see **[About Bare](/bare/explanation/use-bare-standalone)**.

<Callout type="info">
This section covers peer-to-peer logic that runs on Bare alone—no Pear app required. If you're building or shipping a Pear app instead (staging, seeding, provisioning, updating), see the how-to guides on the [Pear tab](/pear/how-to).
</Callout>
