These guides show how to talk to **devices in the same room** over Bluetooth Low Energy with [`bare-bluetooth`](/bare/reference/bare/modules/bare-bluetooth): no Wi-Fi, no internet, no server. Each guide builds on code that already ships upstream, so you can run it as-is before you change it.

<Callout type="tip">
For how the pieces fit together, read [Bluetooth in Bare](/bare/explanation/bluetooth) first. For the rules that make your code reliable on real devices, read [Bluetooth best practices](/bare/explanation/bluetooth/best-practices).
</Callout>
