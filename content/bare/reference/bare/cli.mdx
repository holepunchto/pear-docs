The `bare` command runs a script on the [Bare runtime](/bare/reference/bare/runtime) or starts a REPL. Install it globally with:

```sh
npm i -g bare
```

## Usage

```
bare [flags] [filename] [...args]
```

Evaluate a script, or start a REPL session if no script is provided.

### Arguments

```
  [filename]              Optional. The name of a script to evaluate
  [...args]               Additional arguments made available to the script
```

Arguments after `filename` are passed through to the script and are available as [`Bare.argv`](/bare/reference/bare/runtime#bareargv). `filename` is resolved against the current directory, and `Bare.argv` becomes the executable, the resolved path of `filename`, and then `...args`.

### Flags

```
  --version|-v            Print the Bare version
  --eval|-e <script>      Evaluate an inline script
  --print|-p <script>     Evaluate an inline script and print the result
  --inspect               Activate the inspector
  --inspect-port <port>   Port for the inspector (default: 9229)   [!version since=1.28.1]
  --expose-gc             Expose garbage collection APIs   [!version since=1.27.0]
  --help|-h               Show help
```

`--print` wraps its script as `console.log(<script>)`, so it prints the value of an expression. `--version` prints [`Bare.version`](/bare/reference/bare/runtime#bareversion), which has a leading `v`. An unknown flag or argument prints `unknown flag: <name>` or `unknown argument: <value>` to `stderr`, and an invalid flag prints `invalid flag: <name>`. Each exits with status `1`.

### Inspector

`--inspect` starts the inspector on `--inspect-port` as the script starts. Where the platform has `SIGUSR1`, sending that signal to a running `bare` process starts the inspector too, without `--inspect`. The inspector server doesn't keep the process alive.

### Environment

If `BARE_CHANNEL_FD` is a file descriptor and `BARE_CHANNEL_SERIALIZATION_MODE` is `binary`, `bare` opens that descriptor as an IPC pipe and sets [`Bare.IPC`](/bare/reference/bare/runtime#bareipc) to it, so a parent process can talk to the script it spawned. Requires Bare `>=1.28.7`. With anything else, `Bare.IPC` stays `null`.

## Module loading

The specified `filename` (or inline `--eval` script) is run with `Module.load()`, which resolves both CommonJS and ESM and provides interop between them. An inline script is resolved against the current directory. For the supported formats and resolution rules, see [`bare-module`](https://github.com/holepunchto/bare-module).

With no `filename`, `--eval` or `--print`, `bare` starts a REPL on the global scope, with `require()` resolving against the current directory. The REPL exits when you close it, or once the inspector server has closed if one is running.
