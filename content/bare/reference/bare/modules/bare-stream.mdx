[`bare-stream`](https://github.com/holepunchto/bare-stream) — Streaming data for JavaScript.

Mirrors the Node.js [`stream`](https://nodejs.org/api/stream.html) module: the classic `Readable`/`Writable`/`Duplex`/`Transform` classes are backed by [`streamx`](https://github.com/mafintosh/streamx), while `bare-stream/web` provides a `node:stream/web`-compatible implementation of the WHATWG Streams Standard.

```sh
npm i bare-stream
```

## Usage

```js
const { Readable } = require('bare-stream')

const stream = new Readable({
  read(size) {
    // Push data, then push `null` to signal the end
    this.push('hello')
    this.push('world')
    this.push(null)
  }
})

stream.on('data', (data) => console.log(data))
```
