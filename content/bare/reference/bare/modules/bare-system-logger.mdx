[`bare-system-logger`](https://github.com/holepunchto/bare-system-logger) — System logger for Bare. It is a native addon.

```sh
npm i bare-system-logger
```

## Usage

```js
const SystemLog = require('bare-system-logger')

const log = new SystemLog()

log.info('Hello %s', 'world!')
```

## API

### SystemLog

#### `clear(): void`

#### `colors: boolean`

#### `debug(...data: unknown[]): void`

Log `data` at the `debug` level, formatted printf-style via [`bare-format`](/bare/reference/bare/modules/bare-format).

**Parameters**

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `data` | `unknown[]` | — | Values to log; if the first is a string containing `%s`/`%d`/`%i`/`%f`/`%j`/`%o`/`%O`/`%c` placeholders, the rest substitute into it. |
