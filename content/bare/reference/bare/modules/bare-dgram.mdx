[`bare-dgram`](https://github.com/holepunchto/bare-dgram) — Native UDP sockets for JavaScript. It is a native addon and requires Bare `>=1.16.0`.

Mirrors the Node.js [`dgram`](https://nodejs.org/api/dgram.html) module.

```sh
npm i bare-dgram
```

## Usage

```js
const dgram = require('bare-dgram')

const client = dgram.createSocket('udp4')
const server = dgram.createSocket('udp4')

client.on('connect', () => client.send('hello'))

server.on('message', (msg, rinfo) => {
  console.log(`message: ${msg} from: ${rinfo.address}:${rinfo.port}`)
})

server.bind(() => client.connect(server.address().port))
```

#### `address(): DgramSocketAddress | null`

Returns the address information for the local end of the socket, or `null` if the socket is not bound. A link-local IPv6 address is reported with its zone identifier, for example `fe80::1%en0`, so the value can always be passed back to the socket.

#### `addSourceSpecificMembership(source: string, group: string, iface?: string | null): void`

**Parameters**

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |

| `group` | `string` | — | The multicast group address to join. |
| `iface?` | `string` \| `null` | — | The interface to join on; joins on all applicable interfaces when omitted or `null`. |

#### `bind(port?: number, address?: string, onlistening?: () => void): this`

Bind the socket to `port` and `address` and start receiving datagrams. If `port` is omitted or `0`, an available port is chosen automatically. If `address` is omitted or empty, the socket binds to all interfaces; otherwise a non-IP `address` is resolved using the socket's `lookup` option. Addresses may carry a zone identifier such as `fe80::1%en0`, and must be at most `constants.address.MAX_LENGTH` bytes. Binding errors are reported through the `'error'` event rather than thrown. Returns `this`.

Overloads:

```ts
bind(port?: number, address?: string, onlistening?: () => void): this
bind(port: number, onlistening: () => void): this
bind(opts: DgramSocketBindOptions, onlistening?: () => void): this
bind(onlistening: () => void): this
```

**Parameters**

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `port?` | `number` | `0` | The local port to bind to; `0` picks an available port automatically. |
| `address?` | `string` | — | The local address to bind to; binds to all interfaces when omitted or empty. |
| `onlistening?` | `() => void` | — | Added as a one-time listener for the `'listening'` event, if provided. |

#### `connect(port: number, address?: string, onconnect?: () => void): this`

Connect the socket to a remote `port` and `address`, binding it first if it is not already bound. A connected socket sends to its peer by default and only receives datagrams from it. If `address` is omitted or empty, the loopback address is used. Unlike `bind()`, `port` must be between `1` and `65535`. Returns `this`.

#### `send`

```ts
send(msg: DgramMessage, offset: number, length: number, port?: number, address?: string, cb?: (err: Error | null, bytes: number) => void): void
```

Send `msg` to `port` and `address`, binding the socket first if it is not already bound. `offset` and `length` restrict the send to a subrange of `msg` and may only be given when `msg` is not an array. If the socket is connected, `port` and `address` must be omitted and the datagram is sent to the peer; otherwise `port` must be between `1` and `65535`, and a non-IP `address` is resolved using the socket's `lookup` option. `cb` is called as `cb(err, bytes)` once the datagram has been handed off to the operating system; without a `cb`, send errors are emitted as `'error'` events instead.

**Parameters**

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `msg` | [`DgramMessage`](#dgrammessage) | — | The data to send — a string, `Buffer`, typed array, `DataView`, or an array of these sent as a single datagram. |
| `offset` | `number` | — | Byte offset into `msg` to start sending from; only valid when `msg` is not an array. |
| `length` | `number` | — | Number of bytes of `msg` to send; only valid when `msg` is not an array. |
| `port?` | `number` | — | The remote port; omit when the socket is connected. |
| `address?` | `string` | — | The remote address; omit when the socket is connected. |
| `cb?` | `(err: Error \| null, bytes: number) => void` | — | Called once the datagram has been handed off to the operating system. |

```ts
  address?: string

```

Options for `bind()`. `fd` adopts an existing file descriptor instead of creating and binding a new socket, and requires a socket created with `type: null`.

#### `DgramSocketConnectOptions`

```ts
interface DgramSocketConnectOptions {
  address?: string
  port: number
}
```

Options for `connect()`. `port` must be between `1` and `65535`.

#### `DgramSocketEvents`

```ts
interface DgramSocketEvents {
  close: []
  connect: []
  error: [err: Error]
  listening: []
  message: [message: Buffer, remote: DgramRemoteInfo]
}
```

`'listening'` fires once the socket is bound and ready to receive; `'connect'` once it is connected to its peer; `'message'` for each received datagram; `'close'` once the socket has closed; and `'error'` when binding, receiving, or an uncallbacked send fails. As with any `bare-events` emitter, an `'error'` emitted with no listener attached surfaces as an uncaught exception.

#### `DgramSocketOptions`

```ts
interface DgramSocketOptions {
  ipv6Only?: boolean
  lookup?: DNSLookup
  readBufferSize?: number
  recvBufferSize?: number
  reuseAddr?: boolean
  reusePort?: boolean
  sendBufferSize?: number
  type?: DgramSocketType | null
}
```

`type` is the socket's address family, `'udp4'` or `'udp6'`; pass `null` to leave it unspecified, which is required to later adopt an existing file descriptor. `ipv6Only` (default `false`) binds to IPv6 addresses only rather than dual stack. `reuseAddr` and `reusePort` (both default `false`) allow several sockets to bind the same address and port, with `reusePort` additionally distributing incoming datagrams between them. `readBufferSize` (default `65536`) sizes the buffer datagrams are read into; it defaults larger than the largest possible datagram, so a smaller value can truncate one, which surfaces as an `'error'` event carrying `EMSGSIZE` rather than silently losing data — the socket keeps receiving afterwards. `recvBufferSize` and `sendBufferSize` (both default `0`, meaning the operating system default) size the underlying OS receive and send buffers, applied when the socket is bound. `lookup` (default the `lookup` export of `bare-dns`) resolves hostnames as `lookup(hostname, { family }, cb)` with `cb(err, address, family)`; the resolved `family` is always derived from the returned address rather than what the resolver reports, so a result that isn't an IP address string is treated as a failed lookup.

#### `DgramSocketType`

```ts
type DgramSocketType = 'udp4' | 'udp6'
```

## IPC handle passing

`DgramSocket` implements the `IPCAcceptable` protocol, so a bound socket can be passed to a peer over a [`bare-pipe`](/bare/reference/bare/modules/bare-pipe) created with `ipc: true`, and a received socket can be adopted on the other side with `pipe.accept(socket)`.
