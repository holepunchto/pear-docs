Reference is the technical description of how Bare works. It's information-oriented: comprehensive, accurate, and dry. Use it to look up an API signature or a module.

If you're trying to accomplish a specific task, see **[How To](/bare/how-to)**. For the design rationale, see **[About Bare](/bare/explanation/use-bare-standalone)**.

## In this section

### Bare

- [Bare runtime API](/bare/reference/bare/runtime)—the `Bare` global: process properties, lifecycle, addons, threads, IPC.
- [Bare CLI](/bare/reference/bare/cli)—run a script or REPL with the `bare` command.
- [Bare Kit](/bare/reference/bare/bare-kit)—the Worklet and IPC API for iOS, Android, and React Native.
- [Native-addon CI prebuilds](/bare/reference/native-addon-prebuilds)—building and publishing prebuilt native addons.

### Module catalog

- [Bare modules](/bare/reference/modules/bare-modules)—the full `bare-*` standard library, with the Node.js compatibility table.

### Building blocks

The core peer-to-peer primitives Bare (and Pear) are built on:

- [Hypercore](/p2p/reference/building-blocks/hypercore), [Hyperbee](/p2p/reference/building-blocks/hyperbee), [Hyperdrive](/p2p/reference/building-blocks/hyperdrive), [Autobase](/p2p/reference/building-blocks/autobase), [HyperDHT](/p2p/reference/building-blocks/hyperdht), [Hyperswarm](/p2p/reference/building-blocks/hyperswarm).

### Helpers

Higher-level utilities that combine the building blocks:

- [Corestore](/p2p/reference/helpers/corestore), [Localdrive](/p2p/reference/helpers/localdrive), [Mirrordrive](/p2p/reference/helpers/mirrordrive), [Secretstream](/p2p/reference/helpers/secretstream), [Compact-encoding](/p2p/reference/helpers/compact-encoding), [Protomux](/p2p/reference/helpers/protomux).

### Tools

CLI utilities built on Bare:

- [Hypershell](/p2p/reference/tools/hypershell), [Hypertele](/p2p/reference/tools/hypertele), [Hyperbeam](/p2p/reference/tools/hyperbeam), [Hyperssh](/p2p/reference/tools/hyperssh), [Drives](/p2p/reference/tools/drives).

For Pear's CLI, configuration, and release tooling, see [Pear's Reference](/pear/reference).

## Stability legend

Module pages call out a stability indicator. The four levels:

|                           Stability                                |                         Description                         |
| ------------------------------------------------------------------ | ----------------------------------------------------------- |
| <Status level="stable" />       | Unlikely to change or be removed in the foreseeable future.  |
| <Status level="experimental" /> | New, untested, or has known issues.                          |
| <Status level="deprecated" />   | Being removed or replaced in the future.                     |
| <Status level="unstable" />     | May change or be removed without warning.                    |
